## Why

README последний раз обновлялся до версии 0.1.1, а с тех пор в приложении появились меню действий на карточке и удаление архивов, случайное произведение, размер сетки, плавный масштаб, быстрая навигация и направление чтения, запоминание прогресса, режимы поиска, язык Firefox по языку приложения. README по-прежнему пишет «увеличение ×2», не упоминает «Продолжить» и указывает устаревшие размеры сборок. Кроме того, требование `documentation` к README всё ещё говорит, что «интерфейс пока только на русском», хотя он двуязычный. Версия 0.1.3 готовится к выпуску, и витрина репозитория должна ей соответствовать.

## What Changes

- **Возможности** в `README.md` и `README.ru.md` переписываются под текущую версию:
  - Библиотека: размер карточек (ПК) и число колонок (телефон), меню «⋮» (правый клик и долгое нажатие), удаление в корзину, кнопка 🎲 «случайное произведение».
  - Страница произведения: свои и скрытые теги, «Читать» и «Продолжить · стр. N».
  - Читалка: плавный масштаб до 500% (Ctrl+колесо, щипок, двойной тап из настроек), переход к странице по номеру, чтение справа налево, запоминание прогресса и отметка «дочитано».
  - Поиск: режимы «При вводе» и «По кнопке», поиск по своим и скрытым тегам, 🎲 по результату.
  - Встроенный браузер: язык Firefox следует языку приложения.
- **Названия элементов интерфейса** в английском README даются так, как они написаны в английском интерфейсе (например, **Browser**, **Settings**), а не по-русски.
- **Размеры сборок** в таблице «Download / Скачать» и в системных требованиях сверяются с фактическими артефактами 0.1.3.
- **Описание документации** в README дополняется темами, появившимися в руководстве пользователя (меню карточки, удаление, редактирование тегов, прогресс чтения).
- Требование `documentation` «README как витрина проекта» приводится в соответствие с двуязычным интерфейсом и фиксирует, что список возможностей отражает текущую версию.

Платформы: изменение только документации; различия Windows/Android (размер карточек и колонки, корзина и SAF, Ctrl+колесо и щипок, «Показать в папке») указываются в тексте README.

## Non-goals

- Новые скриншоты: используются имеющиеся `docs/images/` (можно добавить отдельно).
- Правки `docs/*/user-guide.md`, `building.md`, `architecture.md`, `CONTRIBUTING` — они обновлялись вместе со своими изменениями.
- Требование «Руководство пользователя» (названия элементов «по-русски») — отдельное уточнение спецификации.
- Изменения кода приложения.
