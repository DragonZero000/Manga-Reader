## ADDED Requirements

### Requirement: Язык браузера на Windows
На Windows встроенный Firefox SHALL показывать интерфейс на языке приложения (см. `localization`). Базовая сборка Firefox ESR MUST быть `en-US`; для каждого другого языка приложения в папку браузера MUST входить языковой пакет той же версии ESR, проверенный по контрольной сумме при сборке. Язык интерфейса Firefox MUST задаваться при каждом запуске браузера; если языка приложения нет среди языковых пакетов, MUST использоваться English. Язык страниц (Accept-Language) MUST NOT записываться приложением принудительно: по умолчанию он следует языку интерфейса Firefox, а значение, выбранное пользователем в настройках Firefox, MUST сохраняться. Подсказка кнопки встроенного расширения MangaReader MUST быть на языке интерфейса Firefox. Строки Firefox, отсутствующие в языковом пакете, MUST показываться на английском.

#### Scenario: Русский интерфейс
- **WHEN** в приложении выбран Русский, и пользователь открывает браузер
- **THEN** меню, настройки и панель Firefox на русском, подсказка кнопки MangaReader — «MangaReader — показать приложение»

#### Scenario: Английский интерфейс
- **WHEN** в приложении выбран English, и пользователь открывает браузер
- **THEN** меню, настройки и панель Firefox на английском, подсказка кнопки MangaReader — «MangaReader — show the app»

#### Scenario: Смена языка
- **WHEN** браузер открывался на русском, пользователь выбрал English, перезапустил приложение и открыл браузер
- **THEN** Firefox на английском, закладки, расширения и вход на сайты сохранены

#### Scenario: Язык страниц по умолчанию
- **WHEN** в приложении выбран English, пользователь не менял языки страниц в Firefox
- **THEN** сайты получают `Accept-Language`, начинающийся с `en-US`

#### Scenario: Язык страниц выбран пользователем
- **WHEN** в приложении выбран English, а пользователь в настройках Firefox поставил первым русский язык страниц и перезапустил браузер
- **THEN** сайты по-прежнему получают `Accept-Language`, начинающийся с `ru`

#### Scenario: Неверная контрольная сумма
- **WHEN** скачанный языковой пакет не совпадает с контрольной суммой
- **THEN** `fetch-firefox` завершается ошибкой, сборка не продолжается
