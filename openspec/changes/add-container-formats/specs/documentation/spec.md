## ADDED Requirements

### Requirement: Описание форматов и источников файлов
Руководство пользователя на английском и русском (`docs/en/user-guide.md`, `docs/ru/user-guide.md`) SHALL описывать поддерживаемые форматы контейнеров (zip с любым расширением, включая `.cbz`; RAR и 7z, если включены), метаданные `meta.json` и `ComicInfo.xml` с приоритетом `meta.json` и соответствием полей, а также неподдерживаемые форматы (PDF, EPUB). Руководство MUST содержать раздел «Откуда брать файлы» с таблицей проверенных сайтов: что отдаёт сайт, есть ли метаданные, нужен ли вход. В таблицу MUST попадать только то, что проверено вручную. README MUST упоминать `.cbz` вместе с `.zip`. Тексты ошибок в руководстве MUST совпадать с текстами в приложении.

#### Scenario: Описание на обоих языках
- **WHEN** в `docs/en/user-guide.md` есть раздел «Archive format» с `ComicInfo.xml`
- **THEN** в `docs/ru/user-guide.md` есть соответствующий раздел с тем же набором полей

#### Scenario: Парность проверена тестом
- **WHEN** запускается `go test ./...`
- **THEN** проверка парности и ссылок документации проходит
