- [ ] 1.1 Интерфейс `storage.Deleter` (`CanTrash`, `Delete(rel, permanent)`), проверка пути, `ErrUnsupported`; заглушка для прочих платформ
- [ ] 1.2 Windows: `CanTrash` (`SHQueryRecycleBinW` + тип диска), `Delete` через `SHFileOperationW`/`os.Remove`, `ErrBusy` для блокировок; тесты во временной папке (безвозвратное удаление, путь с `..`, занятый файл)
- [ ] 1.3 Android: JNI `DocumentsContract.deleteDocument` в `saf_android.go`, URI по id документа; ошибка без доступа на запись
- [ ] 1.4 `library.Source.Delete(key, permanent)` + `Invalidate`; тест: после удаления и сканирования галереи нет, ошибки и ссылки не остаются
