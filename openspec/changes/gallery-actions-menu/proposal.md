## Why

Сейчас с карточкой можно сделать только одно — открыть страницу произведения. Чтобы удалить ненужный архив, приходится искать файл в проводнике или файловом менеджере Android. Чтобы открыть источник или скопировать название, нужно заходить на страницу произведения. Меню действий «⋮» делает частые операции доступными прямо из сетки библиотеки и поиска.

## What Changes

- На каждой карточке в библиотеке и поиске появляется полупрозрачная кнопка «⋮» в правом верхнем углу обложки. Она открывает меню:
  - «Открыть»
  - «Читать»
  - «Открыть в браузере» (только если есть ссылка)
  - «Скопировать название»
  - «Показать в папке» (только Windows)
  - «Удалить…»
- Правый клик (ПК) и долгое нажатие (телефон) на карточке открывают то же меню.
- В шапке страницы произведения появляется «⋮» только с действиями, которых нет на самой странице: «Скопировать название», «Показать в папке» (Windows), «Удалить…».
- Удаление всегда с подтверждением:
  - Windows: файл перемещается в корзину. Если на диске корзины нет (флешка, сетевой диск), пользователю предлагается удалить файл безвозвратно.
  - Android: файл удаляется безвозвратно через Storage Access Framework, и подтверждение прямо об этом говорит. Если у папки доступ только на чтение, приложение просит выбрать папку заново с правом записи.
- Удаление отклоняется с сообщением, если произведение открыто в читалке. Сейчас это недостижимо из интерфейса, но проверка закладывается на будущее.
- После удаления карточка сразу исчезает из библиотеки и поиска, а каталог, индекс и ссылки обновляются сканированием.

## Capabilities

### New Capabilities
- `gallery-actions`: меню действий на карточке и странице произведения, копирование названия, «Показать в папке», удаление с подтверждением, проверка открытого произведения, обновление экранов после удаления.

### Modified Capabilities
- `library-storage`: новое требование «Удаление архива» — корзина на Windows, удаление через SAF на Android, проверка наличия корзины.

## Impact

- Код: `internal/ui/screens/card.go`, `grid.go`, `library.go`, `search.go`; `internal/ui/details/details.go`; `internal/ui/shell.go` (колбэки действий, проверка открытого произведения); `internal/storage` (удаление: `trash_windows.go`, `saf_android.go`, заглушка `*_other.go`); `internal/library/source.go` (удаление и немедленное обновление); «Показать в папке» — Windows-код (`SHOpenFolderAndSelectItems`) с заглушкой.
- Платформы: Windows — корзина и «Показать в папке»; Android — удаление через SAF, нужен доступ на запись; Linux (в планах) — заглушка «не поддерживается».
- Строки интерфейса — через `internal/i18n` (изменение делается после `i18n-english`).
- Документация: руководство пользователя на двух языках.
