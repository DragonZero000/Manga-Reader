## MODIFIED Requirements

### Requirement: Контракт индекса поиска
Система SHALL определять интерфейс индекса со следующими операциями: добавление или обновление галереи, удаление галереи по ключу, поиск по запросу с возвратом упорядоченных ключей и общего числа совпадений, получение подсказок тегов по необязательному типу и префиксу имени со счётчиком галерей. Приложение MUST использовать рабочую реализацию интерфейса — индекс в каталоге библиотеки (SQLite); индекс в памяти и пустая реализация остаются для тестов. UI MUST зависеть только от интерфейса.

#### Scenario: Рабочий индекс
- **WHEN** приложение запускается и сканирует библиотеку с `example.zip`
- **THEN** поиск через интерфейс индекса находит `local:example.zip`

#### Scenario: Пустая реализация
- **WHEN** используется пустая реализация индекса
- **THEN** поиск возвращает ноль результатов без ошибки
