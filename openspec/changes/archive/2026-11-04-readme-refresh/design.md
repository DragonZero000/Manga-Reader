## Context

README — витрина репозитория на GitHub. Он был написан в изменении `docs` (2026-09-25) и частично обновлён при `i18n-english`. С тех пор архивированы изменения `search-modes`, `add-random-gallery`, `gallery-grid-size`, `gallery-actions-menu`, `custom-tags`, `user-data`, `firefox-locale`, `archive-entry-names`, `reader-navigation`, `reader-zoom`, `reading-progress`. Руководство пользователя и архитектура обновлялись вместе с ними, README — нет.

Источники фактов для текста:
- возможности — `openspec/specs/*` и `docs/<язык>/user-guide.md`;
- названия элементов интерфейса — `internal/i18n/locales/en.json` и `ru.json`;
- размеры — артефакты `make build-windows` / `make build-android` версии 0.1.3 (сейчас в `dist/`: zip ≈ 160 МБ, распакованная папка ≈ 400 МБ, APK ≈ 140 МБ).

Платформы: меняется только Markdown; кода, build-тегов, потоков UI и сторонних компонентов изменение не касается, `THIRD_PARTY_NOTICES.md` не меняется.

## Goals / Non-Goals

**Goals:**
- Оба README перечисляют возможности версии 0.1.3, с одинаковой структурой и смыслом.
- Английский README использует английские названия элементов интерфейса.
- Размеры в таблицах соответствуют реальным сборкам.
- Спецификация `documentation` больше не противоречит двуязычному интерфейсу.

**Non-Goals:**
- Новые скриншоты и правки остальных документов (см. proposal).

## Decisions

1. **README остаётся коротким: одна строка на группу возможностей.** Список возможностей группируется так же, как сейчас (Library, Gallery page/Metadata, Reader, Search, Browser, Errors, Portable), новые функции добавляются внутрь групп короткими перечислениями. Подробности — по ссылке на user-guide.
   *Альтернатива:* отдельный раздел «What's new in 0.1.3». Отклонена: README не changelog, такой раздел устаревает с каждым релизом; изменения версий описываются в Releases.

2. **Размеры округляются вверх до 5–10 МБ и помечаются «~».** Точные числа меняются с каждой сборкой; округление вверх не обещает меньше, чем есть. Размер на диске для Windows берётся по распакованной папке (сейчас ~400 МБ вместо ~350 МБ), для Android — по APK и оценке после установки.
   *Альтернатива:* убрать размеры. Отклонена: требование спецификации и полезно пользователям с ограниченной памятью телефона.

3. **Английский README — английские названия UI, без русских в скобках.** Интерфейс по умолчанию английский для не-русской системы; русские подписи в английском тексте только путают. Пункт меню «Язык / Language» оставляется как есть — он так и подписан в обоих языках.

4. **Сверка с интерфейсом вручную по `locales/*.json`.** Автоматическая проверка названий в README не вводится: она хрупкая для свободного текста. Ссылки и пары по-прежнему проверяет `internal/archtest/docs_test.go`.

## Risks / Trade-offs

- [Размеры релиза 0.1.3 могут отличаться от локальной сборки в `dist/`] → округление вверх; при выпуске сверить с файлами на странице Releases.
- [README снова отстанет от следующих изменений] → в спецификации явно закреплено соответствие текущей версии; правило из `openspec/config.yaml` уже требует задачи на обновление README при изменении видимого поведения.
- [Расхождение смысла между EN и RU] → обе версии пишутся по одному плану разделов и сверяются построчно в задачах.
