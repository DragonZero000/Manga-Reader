## MODIFIED Requirements

### Requirement: README как витрина проекта
`README.md` и `README.ru.md` SHALL содержать:
- что это за приложение, одним абзацем;
- список возможностей, соответствующий текущей версии приложения (`Version` в `FyneApp.toml`): библиотека и её сетка, меню действий карточки, случайное произведение, метаданные и свои теги, читалка (режимы, масштаб, навигация, направление чтения, прогресс), поиск и его режимы, встроенный браузер, вкладка ошибок, портативность на Windows;
- скриншоты из `docs/images/`, если они есть;
- пометку о языке интерфейса: английский и русский, по умолчанию — язык системы (если перевода нет — английский), выбор — в настройках;
- раздел «Скачать» (ссылка на Releases, назначение каждого файла релиза с примерным размером, проверка контрольных сумм);
- установку на Windows и Android (включая обновление APK поверх);
- системные требования;
- краткий раздел для разработчиков со ссылками на `building.md`, `architecture.md` и `CONTRIBUTING`;
- лицензию и ссылку на `THIRD_PARTY_NOTICES.md`.

Названия элементов интерфейса в README MUST приводиться так, как они написаны в интерфейсе на языке этого README (в `README.md` — по-английски, в `README.ru.md` — по-русски). Возможности, которые различаются по платформам, MUST помечаться платформой. Подробности (формат архива, синтаксис поиска, браузер, секреты) MUST находиться в `docs/`, а не в README.

#### Scenario: Новый посетитель
- **WHEN** человек, не знающий русского, открывает страницу репозитория
- **THEN** из `README.md` он понимает, что это читалка манги для Windows и Android со встроенным браузером, что интерфейс есть на английском и какой файл скачать для своей платформы

#### Scenario: Системные требования
- **WHEN** пользователь ищет, подойдёт ли приложение его устройству
- **THEN** в README указаны Windows 10/11 x64 и Android 11+ arm64, а также что Linux пока не поддерживается

#### Scenario: Возможности текущей версии
- **WHEN** в версии из `FyneApp.toml` есть кнопка «Продолжить · стр. N» и плавный масштаб страницы
- **THEN** список возможностей в обоих README упоминает продолжение чтения с сохранённой страницы и масштаб, а не устаревшее «увеличение ×2»

#### Scenario: Названия на языке README
- **WHEN** `README.md` ссылается на кнопку встроенного браузера
- **THEN** она названа **Browser**, как в английском интерфейсе, а в `README.ru.md` — **Браузер**

#### Scenario: Платформенные различия
- **WHEN** возможность есть только на одной платформе (например, «Показать в папке» на Windows) или работает по-разному (Ctrl+колесо на ПК, щипок на Android)
- **THEN** README указывает платформу рядом с описанием
