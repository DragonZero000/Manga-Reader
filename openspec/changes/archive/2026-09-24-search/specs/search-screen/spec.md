## ADDED Requirements

### Requirement: Ввод и выполнение запроса
Экран «Поиск» SHALL содержать поле запроса. Поиск MUST выполняться по нажатию Enter и автоматически через 300 мс после последнего изменения текста. Поиск MUST выполняться в фоне, а результаты применяться через основной поток; результат устаревшего запроса (текст изменился) MUST отбрасываться.

#### Scenario: Поиск по мере ввода
- **WHEN** пользователь вводит `english` и перестаёт печатать
- **THEN** примерно через 300 мс показываются результаты без нажатия Enter

#### Scenario: Быстрый ввод
- **WHEN** пользователь быстро вводит `eng`, затем `english`
- **THEN** на экране результаты для `english`, а не для `eng`

### Requirement: Результаты
Результаты SHALL показываться сеткой карточек (обложка и название), такой же, как в библиотеке, со строкой «Найдено: N». Нажатие на карточку MUST открывать страницу произведения. Если совпадений нет, MUST показываться «Ничего не найдено».

#### Scenario: Найдено
- **WHEN** выполняется поиск `japan`
- **THEN** показываются «Найдено: 1» и карточка «english name»

#### Scenario: Открытие
- **WHEN** пользователь нажимает на карточку в результатах
- **THEN** открывается страница произведения

#### Scenario: Нет совпадений
- **WHEN** выполняется поиск `zzzz`
- **THEN** показывается «Ничего не найдено», сетка пуста

### Requirement: Ошибки запроса
Если строку запроса не удалось разобрать, под полем ввода SHALL показываться сообщение об ошибке (с проблемным фрагментом), а предыдущие результаты MUST оставаться на экране до исправления запроса.

#### Scenario: Ошибка
- **WHEN** пользователь вводит `pages:>много`
- **THEN** под полем показывается сообщение об ошибке, указывающее на `pages:>много`

### Requirement: Справка при пустом запросе
При пустом поле запроса экран SHALL показывать краткую справку по синтаксису с примерами: поиск по слову, фраза в кавычках, `tag:`, `artist:`, исключение `-tag:`, `pages:>20`, `uploaded:2024`, `size:>10mb`.

#### Scenario: Пустой запрос
- **WHEN** пользователь открывает вкладку «Поиск» с пустым полем
- **THEN** показывается справка с примерами запросов

### Requirement: Поиск с другого экрана
Приложение SHALL позволять открыть вкладку «Поиск» с заданным текстом запроса: поле заполняется, поиск выполняется сразу, открытые слои (страница произведения) закрываются.

#### Scenario: Переход из страницы произведения
- **WHEN** вызывается поиск по тексту `artist:"artist 1"`
- **THEN** страница произведения закрывается, открывается вкладка «Поиск» с этим текстом и результатами

### Requirement: Актуальность результатов
При каждом открытии вкладки «Поиск» и после каждого сканирования библиотеки текущий запрос SHALL выполняться заново, чтобы результаты отражали содержимое папки.

#### Scenario: Новый архив
- **WHEN** в папку добавлен подходящий архив, библиотека пересканирована, а пользователь возвращается на вкладку «Поиск»
- **THEN** новый архив есть в результатах
