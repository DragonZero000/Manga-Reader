## 1. Модель масштаба

- [x] 1.1 `scale` вместо `zoomed`/`zoomFactor` в `pagedView`: `zoomTo(s, p)`, `displayRect` с `fit × scale`, сброс в `showPage`/`preview`; все проверки «увеличено» через `scale > 1`
- [x] 1.2 Тесты геометрии: точка привязки остаётся на месте при увеличении и уменьшении; границы 100–500%; сброс при смене страницы и при колесе без Ctrl

## 2. Ввод на ПК

- [x] 2.1 Ctrl+колесо в `Scrolled` (шаг ×1.25, точка под курсором); тест с подменой проверки Ctrl
- [x] 2.2 `Reader.ZoomShortcuts()`/`Reader.Zoom(action)`; регистрация в `Shell` для Ctrl+«=», Ctrl+«+» (цифровой блок), Ctrl+«−», Ctrl+0 только при открытой читалке в постраничном режиме и без фокуса на поле ввода; тесты «Границы масштаба», «Ctrl+0», «Лента»

## 3. Щипок (Android)

- [x] 3.1 `mobile.Touchable`/`mobile.Movable` в `pagedView`: два пальца — масштаб по расстоянию и привязка к середине; подавление перетаскивания и свайпа; отбрасывание тапа после щипка
- [x] 3.2 Тесты на синтетических `TouchEvent`: разведение 100→200 dp даёт 200% с неподвижной серединой; номер страницы и панель не меняются; одиночный тап после щипка работает

## 4. Двойной тап и настройка

- [x] 4.1 Ключ `reader.double_tap` (`off`/150/200/250/300, по умолчанию 200), `ReaderDoubleTap`/`SetReaderDoubleTap` в `internal/app`; тест неизвестного значения
- [x] 4.2 Читалка: двойной тап 100% ↔ значение из настроек; при «Выключен» тапы без окна ожидания; тесты «Значение из настроек», «Выключен», «Два тапа при выключенном», «Возврат двойным тапом»
- [x] 4.3 Выбор «Двойной тап» в карточке «Читалка»; тест сохранения и тест ширины экрана настроек на телефоне

## 5. Индикатор и чёткость

- [x] 5.1 `zoomBadge`: текст процентов, видимость (постоянно при > 100%, скрытие через 1,5 с при 100%), положение над панелью, тап — 100%; скрыт в ленте; тесты сценариев индикатора
- [x] 5.2 Отложенная чёткая догрузка (`sharpDelay = 200ms`, поколение), ограничение текстуры 3072 на Android; тесты «Догрузка» и «Быстрое изменение» (счётчик декодирований)
