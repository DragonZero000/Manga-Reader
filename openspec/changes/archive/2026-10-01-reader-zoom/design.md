## Context

После `reader-navigation` постраничный вид (`internal/ui/reader/paged.go`) сам распознаёт двойной тап (`tapWindow`, `doubleTapSides`), колесо без Ctrl всегда листает, Ctrl+колесо игнорируется (`ctrlPressed`). Увеличение — флаг `zoomed` и константа `zoomFactor = 2`; геометрия — `pages.Fit`, `pages.ZoomAt`, `pages.ClampOffset`; при увеличении догружается версия `request(page, zoomFactor)` (сторона ≤ `maxTexture = 4096`, загрузчик не увеличивает исходник). Карточка «Читалка» в настройках уже есть (направление чтения).

Проверено в Fyne v2.8.0:
- Клавиши: «=» → `fyne.KeyEqual`, «+» цифрового блока → `fyne.KeyPlus`, «−» обеих клавиатур → `fyne.KeyMinus`, «0» → `fyne.Key0`. Сочетания с Ctrl до `SetOnTypedKey` не доходят надёжно — нужны `Canvas.AddShortcut(&desktop.CustomShortcut{…, Modifier: fyne.KeyModifierShortcutDefault})`.
- Модификаторы при прокрутке — `desktop.Driver.CurrentKeyModifiers()`.
- Мобильный драйвер: `mobile.Touchable` получает `TouchDown/TouchUp` каждого пальца с `ID`, `mobile.Movable.TouchMoved` — движение каждого пальца; `Dragged` — только первый палец. `TouchUp` вызывается раньше `Tapped` того же пальца; отпускание второго пальца после короткого щипка без этого кода превратилось бы в `Tapped`.

## Goals / Non-Goals

**Goals:** непрерывный масштаб 100–500% с точкой привязки; жесты ПК и Android; двойной тап из настроек (или выключен — тогда тапы без окна ожидания); индикатор; чёткая догрузка без рывков.

**Non-Goals:** масштаб ленты, сохранение масштаба между страницами, режимы вписывания.

## Decisions

### 1. Модель масштаба

`zoomed bool` → `scale float32` (1 = вписано, ≤ `maxScale = 5`). `offset` — левый верхний угол изображения, как сейчас. Единая операция:

```go
// zoomTo меняет масштаб так, что точка p области просмотра остаётся над той же точкой изображения.
func (v *pagedView) zoomTo(s float32, p fyne.Position) {
    s = clamp(s, 1, maxScale)
    r := v.displayRect()                     // текущее положение
    v.offset = pages.ZoomAt(r.pos, p, s/v.scale)
    v.scale = s
    v.clamp(); v.Refresh(); v.zoomChanged()  // индикатор + отложенная догрузка
}
```

`displayRect` берёт `fit × scale` вместо `fit × zoomFactor`. `scale > 1` заменяет все проверки `zoomed` (тап-зоны, свайп, перетаскивание). `showPage`/`preview` сбрасывают `scale = 1`. Шаг колеса и клавиш — `zoomStep = 1.25`; Ctrl+0 — `zoomTo(1, центр)`.

Отклонено: хранить масштаб относительно исходника (а не вписанного) — 100% тогда зависит от размера окна и неудобен для индикатора.

### 2. Ввод

- **Ctrl+колесо** — в `Scrolled`: при `ctrlPressed()` — `zoomTo(scale·1.25^sign, ev.Position)` (вверх — увеличить), без `throttled`: каждое событие — шаг.
- **Сочетания** — `Reader.ZoomShortcuts() []fyne.Shortcut` и `Reader.Zoom(action)`; `Shell` регистрирует их `AddShortcut` на canvas и вызывает только когда читалка открыта и режим постраничный (иначе ничего). Действия: in (`KeyEqual`, `KeyPlus`), out (`KeyMinus`), reset (`Key0`).
- **Щипок** — `pagedView` реализует `mobile.Touchable` и `mobile.Movable`: `touches map[int]fyne.Position`. Второй палец → `pinch{d0, s0}`; `TouchMoved` при двух пальцах → `zoomTo(s0·d/d0, середина)`, плюс сдвиг на смещение середины (палец «тащит» страницу). Пока `pinching`: `Dragged`/`DragEnd` ничего не делают (сбрасывают `dragAcc`). Когда отпущен последний палец после щипка — `suppressTap = true`; ближайший `Tapped` (того же отпускания) сбрасывает флаг и игнорируется; любой `TouchDown` тоже сбрасывает флаг.
- **Двойной тап** — `doubleTap(p)`: `scale > 1` → `zoomTo(1, p)`; иначе `zoomTo(r.doubleTapScale, p)`. `doubleTapScale == 0` (выключено) — автомат тапов не ждёт второго тапа ни в одной зоне: `Tapped` сразу вызывает `singleTap`.

### 3. Настройка

`app.KeyReaderDoubleTap = "reader.double_tap"`: `off`, `150`, `200` (по умолчанию), `250`, `300`; `ReaderDoubleTap(s) float32` (0 — выключено, неизвестное → 2). Читалка читает в `Open` вместе с направлением. Экран настроек: в карточке «Читалка» выпадающий список `Select` на обеих платформах — пять вариантов в ряд не помещаются на телефоне (ширина карточки проверяется существующим тестом), а одинаковый элемент проще.

### 4. Индикатор

`zoomBadge` — виджет (полупрозрачный фон, текст «175 %», `Tappable`: тап → `zoomTo(1, центр)`), лежит в слое читалки над видами, но под панелью; позиционируется вручную: правый нижний угол с отступом `theme.Padding()`, а при видимой панели — над её нижней полосой (`Reader.repositionBadge` вызывается при показе/скрытии панели и при изменении размера). Видимость: `scale > 1` — виден; `scale == 1` — показан и скрывается таймером 1,5 с (счётчик поколений против устаревших таймеров, возврат через `r.do`). В ленте скрыт.

Отклонено: индикатор внутри панели — не виден, когда панель скрыта (а скрыта она почти всегда).

### 5. Чёткая догрузка

`zoomChanged` перезапускает таймер `sharpDelay = 200ms` (поколение `sharpSeq`). По срабатыванию (через `r.do`): если `scale > 1` и страница та же — `load(request(page, scale), PriorityCurrent)`. `request` уже ограничивает сторону `maxTexture`; на Android `maxTexture` уменьшается до 3072 (≈36 МБ RGBA при кэше 80 МБ — страница 4096² заняла бы 64 МБ и вытеснила весь кэш). `load` при `scale > 1` не прячет текущее изображение (уже так для `zoomed`) — растянутая картинка остаётся до прихода чёткой; `want` отбрасывает устаревшие результаты. При `scale == 1` после уменьшения — запрос вписанного размера (обычно уже в кэше).

### Потоки

Все жесты, таймеры (`sharpDelay`, скрытие индикатора, окно двойного тапа) изменяют состояние только в UI-потоке: таймеры возвращаются через `r.do` (fyne.Do) и проверяют поколение. `TouchDown/Moved/Up` драйвер вызывает в UI-потоке.

### Платформы

Без build tags. Ctrl+колесо и сочетания существуют только на ПК (на Android `CurrentKeyModifiers` недоступен, `AddShortcut` не срабатывает без клавиатуры). Щипок — только Android: на ПК `mobile.Touchable` не вызывается. Ограничение текстуры — по `fyne.CurrentDevice().IsMobile()`.

## Risks / Trade-offs

- [Щипок нельзя проверить на эмуляторе через adb (нет мультитача в `input`)] → логика щипка — чистые функции и обработчики, покрытые тестами с синтетическими `TouchEvent`; ручная проверка на устройстве — отдельная задача.
- [Догрузка большого изображения 4096 px на ПК занимает сотни мс] → растянутое изображение остаётся на экране, догрузка — только после паузы 200 мс.
- [Сочетания Ctrl+«=» перехватывают поле ввода номера страницы] → поле принимает только цифры, Ctrl-сочетаний не обрабатывает; `Shell` вызывает `Zoom` только без фокуса на поле (проверка `Canvas().Focused() == nil`).
- [Отбрасывание `Tapped` после щипка может съесть настоящий тап] → флаг живёт только до следующего `TouchDown`.
