## Why

Интерфейс сейчас только на русском: около 400 строк зашиты прямо в код, тексты ошибок сохраняются в каталог и настройки уже на русском. Приложение открытое (MIT), и без английского интерфейса им не могут пользоваться те, кто не читает по-русски. Нужна английская локализация и основа, в которую новые языки добавляются файлом переводов без правки кода.

## What Changes

- Новый пакет `internal/i18n`: переводы из встроенных файлов `locales/<язык>.json`, выбор языка, формы множественного числа, форматы дат и размеров.
- Настройка «Язык / Language»: «Системный», «English», «Русский». Язык определяется при запуске: явный выбор, иначе язык системы, если он есть среди переводов, иначе English. Смена вступает в силу после перезапуска.
- Все видимые пользователю тексты (экраны, toast, диалоги, справка поиска, подписи тегов, причины на вкладке «Ошибки») выводятся на выбранном языке. Встроенные тексты Fyne (кнопки диалогов, меню полей ввода) — тоже на выбранном языке, а не на языке системы.
- Ошибки сервисных пакетов становятся типизированными (вид + параметры); `err.Error()` — технический текст на английском; перевод выполняется в UI. **BREAKING (данные)**: версия каталога `library.db` повышается — при первом запуске каталог пересоздаётся и библиотека сканируется целиком.
- Все технические логи (Go и Kotlin) — на английском.
- Браузер Android: строки интерфейса переносятся в ресурсы (`values/` — English, `values-ru/`), язык передаётся из приложения; язык страниц (Accept-Language) по умолчанию совпадает с языком приложения, как в Firefox.
- `openspec/config.yaml` обновляется под двуязычный интерфейс.

**Non-goals:** язык браузера Firefox на Windows (отдельное изменение `firefox-locale`); смена языка без перезапуска; перевод комментариев в коде; языки кроме English и Русского; перевод синтаксиса поиска (`tag:`, `pages:` и т. п.).

## Capabilities

### New Capabilities
- `localization`: выбор и определение языка, полнота переводов, перевод встроенных текстов Fyne, типизированные ошибки и их перевод, язык логов, язык браузера Android.

### Modified Capabilities
- `search-syntax`: требование «Сообщения об ошибках» — причина на языке интерфейса, а не «на русском».

## Impact

- Код: весь `internal/ui`; ошибки в `internal/library`, `internal/search`, `internal/storage`, `internal/browser`, `internal/mobilebrowser`, `internal/problems`, `internal/catalog` (версия схемы); `internal/app` (настройка языка); Kotlin `android/app/src/main/kotlin/.../browser/*` и `res/values*`.
- Новый пакет `internal/i18n` → `internal/archtest` и `docs/*/architecture.md`.
- Зависимость `github.com/nicksnyder/go-i18n/v2` становится прямой (уже есть в сборке через Fyne); копии `base.en.json` / `base.ru.json` из Fyne (BSD-3) → `THIRD_PARTY_NOTICES.md`.
- Размер: exe/apk ≈ +30–50 КБ.
- Тесты: около 55 тестовых файлов проверяют русские строки — фиксируют язык `ru`.
- Платформы: Windows и Android; Kotlin-часть — только Android.
- Документация: README и docs на двух языках.
