## Context

После `reader` оболочка — `Stack(tabs, reader, toast)`; карточка библиотеки вызывает `Reader.Open`. `model.Gallery` уже содержит все поля `meta.json` (названия, теги с типами, ID, дата, избранное, сканлейтор, `NumPages`) и сведения о файле. Для изображений есть `thumbs.Cache` (миниатюры 320 px) и `pages.Loader` (загрузка с уменьшением до области).

Из опыта `reader`: в Fyne 2.8 `Container.Show()` не перерисовывает, а объект, скрытый с момента создания, не получает перерисовку через собственный `Refresh` — нужен `Window.Canvas().Refresh(o)`. Сеть, API и rate limiting в этом изменении не используются.

## Goals / Non-Goals

**Goals:** экран сведений между библиотекой и читалкой; корректная цепочка «Назад»; форматирование сведений в тестируемых чистых функциях.

**Non-Goals:** поиск по тегу, редактирование, миниатюры всех страниц (см. proposal).

## Decisions

### D1. Слой поверх вкладок, как у читалки

`Stack(tabs, details, reader, toast)`. Страница произведения — непрозрачный слой; читалка выше неё, поэтому «Читать» просто открывает читалку, а её закрытие возвращает на страницу произведения без дополнительной логики. Вкладки под слоями не пересоздаются (прокрутка сетки сохраняется).

*Альтернатива:* стек навигации внутри вкладки «Библиотека». Отклонено: на телефоне нижние вкладки заняли бы место, а для обложки нужна вся высота; кроме того, слой уже проверен на читалке.

### D2. Цепочка «Назад»/Esc

`Shell.typedKey`: читалка видима → закрыть читалку (как сейчас); иначе страница произведения видима → Esc/Back закрывают её, прочие клавиши игнорируются (прокрутка — колесом и пальцем); иначе Back → `GoBack`. Верхняя полоса страницы — кнопка «Назад» (иконка `NavigateBackIcon`) и название, обрезанное многоточием.

### D3. Пакет `internal/ui/details`

```
details/
  details.go  — Details: слой, Open(g)/Close()/Visible(), сборка содержимого, обложка
  format.go   — чистые функции: TagGroups(tags) []Group, InfoRows(g, libDir) []Row,
                FormatSize, FormatDate, FormatDateTime, FormatInt (разряды)
  format_test.go
```

Содержимое собирается заново при каждом `Open` (дёшево: десятки виджетов), `VScroll` сбрасывается в начало. Ссылки на читалку нет: `details.New(..., onRead func(model.Gallery))` — оболочка передаёт `Reader.Open`.

### D4. Группировка тегов

Известные типы в порядке `artist, group, parody, character, language, category, tag` с русскими подписями; неизвестные — после, по алфавиту, подпись = тип. Внутри группы — порядок `Gallery.Tags` (порядок `meta.json`). Отображение: строка «Подпись:» + контейнер `layout.NewRowWrapLayout()` с «чипами» (скруглённый прямоугольник `ColorNameInputBackground` + `widget.Label`). Чипы неинтерактивны (поиск по тегу — `search`).

### D5. Сведения

Сетка из двух колонок `container.New(layout.NewFormLayout(), ...)`: подпись (жирная) — значение (перенос по словам). Форматы: дата `02.01.2006`, дата-время `02.01.2006 15:04` в локальном часовом поясе (дата загрузки хранится в UTC — показывается как UTC-дата, чтобы не «съезжать» на день), размер — `31,0 КБ` (основание 1024, запятая как десятичный разделитель, одна цифра после запятой; меньше 1 КБ — «N Б»), числа — с неразрывным пробелом между разрядами. Путь файла — относительно папки библиотеки (`Key.ID`).

Правило пустых значений одно для всех полей: `InfoRows` не возвращает строку, если значение пустое (строка после `TrimSpace` пустая, число 0, `time.IsZero()`). Исключений нет — даже «Страниц», «Файл», «Размер», «Изменён» скрываются при пустом значении. Если строк нет, экран не добавляет раздел сведений. То же правило уже действует для альтернативного названия и групп тегов.

### D6. Обложка

- Целевая область: ширина = ширина содержимого, высота ≤ 60% высоты окна; изображение вписывается (`pages.Fit`) и центрируется. Реализация — собственный виджет `cover` с `canvas.Image` (`ImageFillContain`) и фиксированным `MinSize`, вычисляемым из размера изображения и ширины окна (пересчёт при изменении размера окна).
- Мгновенно показывается миниатюра из `thumbs.Cache.Cached(g)` (если есть), затем запрашивается изображение через **отдельный** `pages.Loader` страницы произведения (кэш 32 МБ, 1 воркер) размером «область × плотность экрана»; результат применяется через `fyne.Do` с проверкой, что открыта та же галерея. Отдельный загрузчик — чтобы `Reader.Close` (очищающий свой кэш) не выбрасывал обложку и чтобы кэши не конкурировали.
- Ошибка загрузки → значок `theme.BrokenImageIcon()`; остальное содержимое не зависит от обложки.
- `cover` реализует `Tappable` → `onRead(g)`.
- При закрытии страницы кэш её загрузчика очищается.

### D7. Потоки UI (явно)

Загрузка обложки — в воркере загрузчика; применение — через подменяемую функцию `do` (по умолчанию `fyne.Do`), как в `reader`, чтобы UI-тесты на тестовом драйвере Fyne были без гонок. Состояние экрана меняется только в UI-потоке. Показ/скрытие слоя — с `Window.Canvas().Refresh`.

## Risks / Trade-offs

- [Двойная загрузка первой страницы: обложка + читалка] → разные размеры и кэши; первая страница читалки декодируется заново (десятки мс). Приемлемо; объединение кэшей — позже при необходимости.
- [Длинный список тегов на телефоне] → перенос по строкам и общая прокрутка страницы; нагрузка незначительна.
- [Esc/«Назад» на ПК при фокусе на кнопке] → клавиши идут в `Canvas.OnTypedKey` только без фокуса; при открытии страницы вызывается `Canvas().Unfocus()`.

## Open Questions

- Показывать ли на странице дату «добавлено в библиотеку» отдельно от даты изменения файла — сейчас их не различить (нет хранилища).

## Implementation notes (2026-09-24)

- **Теги — в две колонки** (`FormLayout`: подпись типа слева, чипы в `RowWrapLayout` справа), как и сведения. Первый вариант (подпись над чипами) занимал по две строки на группу. `RowWrapLayout` узнаёт настоящую высоту только после первой раскладки, поэтому после сборки содержимого выполняется ещё один `body.Refresh()` через `do`.
- Альтернативное название — курсивом обычной яркости: `LowImportance` на тёмной теме почти не видно.
- Для UI-тестов у `Details`, `Reader` и `Toast` подменяемый диспетчер (`SetDispatcher` / поле `do`); очередь своя у каждого теста — иначе воркеры загрузчиков прошлых тестов гонялись за общую переменную. Под `-race` стабильно проходят `internal/ui/...` (3 прогона подряд). Попутно исправлена гонка в старых тестах toast, впервые запущенных под `-race`.
- Проверено: Windows (страница `example.zip`, битая обложка, обложка вебтуна, «Читать» → Esc → Esc) и эмулятор Android 15 (узкий экран, «Назад» по цепочке до сворачивания приложения).
