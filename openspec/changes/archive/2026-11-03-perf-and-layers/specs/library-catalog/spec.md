## MODIFIED Requirements

### Requirement: Файл каталога
Приложение SHALL хранить каталог библиотеки в одном файле SQLite: на ПК — `library.db` в папке приложения рядом с `settings.json`, на Android — `library.db` в личной папке приложения. Каталог содержит разобранные галереи, ошибочные файлы с причиной и поисковые данные для папки библиотеки, для которой он создан; уменьшенные обложки хранятся отдельно, в кэше обложек (см. «Обложки в каталоге»). Каталог MUST NOT храниться в папке библиотеки.

#### Scenario: ПК
- **WHEN** приложение на Windows запущено и библиотека просканирована
- **THEN** рядом с `mangareader.exe` есть `library.db`, в папке `manga` новых файлов нет

#### Scenario: Android
- **WHEN** приложение на Android запущено с выбранной папкой `Download/manga`
- **THEN** каталог создан в личной папке приложения, в `Download/manga` новых файлов нет

### Requirement: Обложки в каталоге
Уменьшенные обложки SHALL храниться не в каталоге, а файлами JPEG в кэше обложек: на Android — в системной папке кэша приложения (`getCacheDir()/covers`), на ПК — в папке `cache/thumbs` рядом с исполняемым файлом. Имя файла строится из ключа галереи (путь, время изменения архива) и размера области обложки. Когда нужна миниатюра, которой нет в памяти, приложение MUST сначала взять её из кэша обложек и только при её отсутствии декодировать первую страницу архива; созданная миниатюра MUST сохраняться в кэш обложек. При сохранении обложки другого размера для той же галереи прежний файл MUST удаляться; обложка другого размера области MUST NOT использоваться. После каждого сканирования файлы обложек галерей, которых больше нет в библиотеке (удалённые и изменённые архивы), MUST удаляться вне UI-потока. При смене папки библиотеки (Android) кэш обложек MUST очищаться. Каталог прежней версии с таблицей обложек MUST открываться без повторного сканирования: таблица удаляется, место в файле освобождается.

#### Scenario: Обложка после перезапуска
- **WHEN** обложки библиотеки показаны, приложение перезапущено и сетка прокручена
- **THEN** обложки показываются из кэша обложек, архивы для обложек не открываются

#### Scenario: Изменённый архив
- **WHEN** архив заменён другим с новой первой страницей и библиотека пересканирована
- **THEN** карточка показывает новую обложку, файл прежней обложки удалён

#### Scenario: Системный кэш (Android)
- **WHEN** на Android показано 83 обложки
- **THEN** их объём учитывается системой в «Кэше» приложения, а не в «Данных», и «Очистить кэш» в настройках Android их удаляет

#### Scenario: Переход с каталога прежней версии
- **WHEN** приложение запускается с каталогом, в котором обложки хранились в таблице
- **THEN** библиотека показывается из каталога без повторного сканирования, таблица обложек удалена, файл каталога уменьшился

## ADDED Requirements

### Requirement: Размер и очистка кэша обложек
В «Настройках» SHALL быть строка «Кэш обложек» с объёмом файлов кэша обложек (в МБ с одним знаком после запятой) и кнопкой «Очистить». Объём MUST подсчитываться вне UI-потока при каждом открытии вкладки «Настройки» и после очистки; пока подсчёт идёт, вместо числа MUST показываться «…».

Кнопка «Очистить» MUST без диалога подтверждения удалять все файлы кэша обложек. По окончании MUST показываться уведомление «Кэш обложек очищен». Очистка MUST выполняться вне UI-потока; миниатюры в памяти MUST NOT удаляться, поэтому видимые карточки не меняются. Удалённые обложки создаются заново из архивов по мере показа карточек. Пока очистка идёт, кнопка MUST быть недоступна. Кэш обложек MUST работать и без каталога (SQLite недоступен).

#### Scenario: Показ объёма
- **WHEN** в кэше 200 обложек по 50 КБ, и пользователь открывает вкладку «Настройки»
- **THEN** сначала показывается «…», затем «Кэш обложек: 9,8 МБ»

#### Scenario: Очистка
- **WHEN** пользователь нажимает «Очистить»
- **THEN** файлы обложек удалены, показано уведомление «Кэш обложек очищен», строка показывает «0 МБ», а сетка библиотеки показывает прежние обложки из памяти

#### Scenario: Обложки после очистки
- **WHEN** после очистки приложение перезапущено и сетка прокручена
- **THEN** обложки создаются из архивов и снова сохраняются в кэш обложек
