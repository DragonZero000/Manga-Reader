## ADDED Requirements

### Requirement: Dev-сборка
`make build-android-dev` SHALL собирать `dist/mangareader-dev.apk` — отдельное приложение «MangaReader Dev» с ID `io.github.mangareader.app.dev` и версией с суффиксом `-dev`. Оно MUST ставиться рядом с обычным приложением, со своими настройками, папкой библиотеки, каталогом и данными браузера. Поведение dev-сборки MUST совпадать с обычной, кроме раздела «Разработка» в «Настройках»; ничего из инструментов разработки MUST NOT запускаться само.

В разделе «Разработка» SHALL быть:
- кнопка «Запустить тесты» — сценарии автопрокрутки замера кадров (библиотека, поиск, страница произведения, настройки, лента, постраничный режим, вкладки, плотность сетки); пока они идут, кнопки раздела недоступны, а по окончании выбранная вкладка и настройки возвращаются;
- кнопка «Ручной замер» / «Остановить замер» — запись интервалов кадров, пока пользователь сам листает; при остановке — одна сводка `manual`;
- по окончании тестов или ручного замера отчёт MUST сохраняться в файл: на Android — в скрытую папку `.perf` в папке библиотеки (сканер её пропускает), на ПК — в папку `perf` рядом с исполняемым файлом; имя `perf-ГГГГММДД-ЧЧММСС.txt`;
- кнопка «Поделиться» (Android) — системное меню «Поделиться» с текстом последнего отчёта; на ПК вместо неё «Открыть папку» с отчётами.

Отчёт MUST содержать версию, устройство, размер и масштаб экрана, настройку «Ограничить 60 Гц» (Android), плотность сетки и число галерей, затем по строке сводки на каждый сценарий (`n`, `p50`, `p95`, `max`, `slow`, `>25ms`, `gc`, `gcmax`, `heap`). Обычная сборка (`make build-android`) раздела «Разработка» MUST NOT содержать.

#### Scenario: Установка рядом
- **WHEN** на телефоне стоит MangaReader, и пользователь ставит `mangareader-dev.apk`
- **THEN** в списке приложений два приложения: «MangaReader» и «MangaReader Dev», данные обычного не затронуты

#### Scenario: Тесты по кнопке
- **WHEN** пользователь запускает dev-сборку
- **THEN** сценарии не запускаются, пока он не нажмёт «Запустить тесты» в «Настройках» → «Разработка»

#### Scenario: Отчёт в файл и «Поделиться»
- **WHEN** тесты закончились на Android с папкой библиотеки `Download/Manga`
- **THEN** создан файл `Download/Manga/.perf/perf-….txt`, показано уведомление с его именем, а «Поделиться» открывает системное меню с текстом отчёта

#### Scenario: Обычная сборка
- **WHEN** собран `make build-android`
- **THEN** в «Настройках» нет раздела «Разработка»
