## ADDED Requirements

### Requirement: Удаление архива
Хранилище библиотеки SHALL уметь удалять файл по пути относительно папки библиотеки и сообщать, будет ли удаление обратимым:
- Windows: файл MUST перемещаться в корзину Windows. Если для диска папки библиотеки корзины нет, хранилище MUST сообщать об этом до удаления; безвозвратное удаление MUST выполняться только по явному запросу.
- Android: файл MUST удаляться через Storage Access Framework (удаление документа выбранной папки); удаление всегда безвозвратное. Если постоянного доступа на запись нет, MUST возвращаться ошибка отсутствия доступа на запись без попытки удаления.
- Прочие платформы: MUST возвращаться ошибка «не поддерживается».

Занятый другим процессом файл MUST давать ошибку вида «файл занят» (`ErrBusy`). Путь MUST NOT выходить за пределы папки библиотеки.

#### Scenario: Корзина на Windows
- **WHEN** хранилище на локальном диске NTFS удаляет `a.zip`
- **THEN** `a.zip` оказывается в корзине и восстанавливается оттуда

#### Scenario: Диск без корзины
- **WHEN** папка библиотеки на сетевом диске
- **THEN** хранилище сообщает, что корзины нет, и не удаляет файл без явного запроса безвозвратного удаления

#### Scenario: Удаление через SAF
- **WHEN** на Android с доступом на запись удаляется `series/vol1.zip`
- **THEN** файл исчезает из `Download/manga/series`, следующее сканирование его не находит

#### Scenario: Путь за пределами папки
- **WHEN** запрошено удаление `../other.zip`
- **THEN** возвращается ошибка, файлы вне папки библиотеки не затрагиваются
