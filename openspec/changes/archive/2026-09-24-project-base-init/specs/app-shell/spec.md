## ADDED Requirements

### Requirement: Приложение запускается на ПК и Android
Приложение SHALL собираться из одного Go-модуля в Windows-исполняемый файл и Android-пакет и при запуске MUST показывать главное окно с оболочкой навигации без ошибок.

#### Scenario: Запуск на Windows
- **WHEN** пользователь запускает собранный `mangareader.exe`
- **THEN** открывается окно с заголовком «MangaReader» и активным экраном «Библиотека»

#### Scenario: Запуск на Android
- **WHEN** пользователь устанавливает и открывает собранный `.apk`
- **THEN** приложение открывается на экране «Библиотека» и не завершается аварийно

### Requirement: Навигация между экранами
Оболочка SHALL предоставлять переключение между экранами «Библиотека», «Поиск» и «Настройки». Все экраны MUST быть доступны из оболочки; переключение MUST NOT пересоздавать окно и MUST сохранять состояние остальных экранов.

#### Scenario: Переключение экрана
- **WHEN** пользователь выбирает «Поиск» в навигации
- **THEN** отображается экран «Поиск», а навигация остаётся видимой

#### Scenario: Возврат на экран
- **WHEN** пользователь переходит с «Библиотеки» на «Настройки» и обратно
- **THEN** экран «Библиотека» показывается в том же состоянии, без повторной инициализации

#### Scenario: Компоновка на узком экране
- **WHEN** ширина окна соответствует мобильному устройству
- **THEN** навигация отображается в виде нижних вкладок, доступных без прокрутки

### Requirement: Неблокирующие toast-уведомления
Оболочка SHALL показывать краткие уведомления поверх текущего экрана. Показ уведомления MUST NOT заменять содержимое окна, и уведомление MUST исчезать автоматически.

#### Scenario: Показ уведомления
- **WHEN** код приложения вызывает показ уведомления с текстом
- **THEN** текст отображается поверх текущего экрана, а экран и навигация остаются видимыми и доступными

#### Scenario: Автоскрытие
- **WHEN** проходит время показа уведомления (по умолчанию 3 секунды)
- **THEN** уведомление исчезает, а содержимое экрана не меняется

#### Scenario: Вызов из фоновой горутины
- **WHEN** уведомление запрашивается из горутины, отличной от UI-потока
- **THEN** уведомление показывается корректно, без предупреждений Fyne о доступе к UI вне основного потока

### Requirement: Обновление UI только через основной поток
Весь код, изменяющий виджеты из фоновых горутин, MUST делать это через `fyne.Do`. Сервисные пакеты (`paths`, `model`, `search`) MUST NOT импортировать пакеты Fyne-виджетов.

#### Scenario: Сервисный пакет без UI
- **WHEN** выполняется проверка импортов пакетов `internal/paths`, `internal/model`, `internal/search`
- **THEN** ни один из них не импортирует `fyne.io/fyne/v2/widget` или `fyne.io/fyne/v2/container`
