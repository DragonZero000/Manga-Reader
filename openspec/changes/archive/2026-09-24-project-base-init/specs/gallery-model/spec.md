## ADDED Requirements

### Requirement: Единая модель произведения
Система SHALL представлять любое произведение, независимо от источника, единой моделью `Gallery` со следующими полями: ключ, внешний ID (необязательный), основное и альтернативное название, типизированные теги, дата загрузки на сайт, количество страниц, количество избранного на сайте, сканлейтор, упорядоченный список страниц, а также сведения о файле (путь, размер, время изменения).

#### Scenario: Модель без метаданных
- **WHEN** создаётся `Gallery` только с ключом и названием
- **THEN** необязательные поля имеют нулевые значения, а список тегов пуст

### Requirement: Ключ галереи с префиксом источника
Ключ галереи MUST иметь вид `<источник>:<локальный идентификатор>` и MUST быть уникальным в пределах приложения. Для локальной библиотеки источник — `local`, идентификатор — имя файла архива относительно папки библиотеки.

#### Scenario: Ключ локального архива
- **WHEN** формируется ключ для файла `example.zip` из папки библиотеки
- **THEN** ключ равен `local:example.zip`

#### Scenario: Разбор ключа
- **WHEN** разбирается ключ `local:example.zip`
- **THEN** источник равен `local`, а идентификатор равен `example.zip`

#### Scenario: Некорректный ключ
- **WHEN** разбирается строка без разделителя `:` или с пустым источником
- **THEN** возвращается ошибка

### Requirement: Выбор основного названия
Основное название MUST выбираться в порядке: английское название, японское название, имя файла без расширения. Альтернативным названием MUST быть японское, если основным выбрано английское и японское не пустое.

#### Scenario: Есть оба названия
- **WHEN** английское название «english name», японское «japanease name»
- **THEN** основное название «english name», альтернативное «japanease name»

#### Scenario: Нет английского названия
- **WHEN** английское название пустое, японское «japanease name»
- **THEN** основное название «japanease name», альтернативное пустое

#### Scenario: Нет названий
- **WHEN** оба названия пустые, файл называется `example.zip`
- **THEN** основное название «example»

### Requirement: Нормализация тегов
Тег SHALL состоять из типа и имени. При создании тега тип и имя MUST приводиться к нижнему регистру, а начальные и конечные пробелы и повторяющиеся внутренние пробелы MUST удаляться. Каноническая строка тега MUST иметь вид `<тип>:<имя>`. Два тега с одинаковой канонической строкой MUST считаться равными.

#### Scenario: Нормализация регистра и пробелов
- **WHEN** создаётся тег с типом «Artist» и именем «  Artist   1 »
- **THEN** тип равен `artist`, имя равно `artist 1`, каноническая строка `artist:artist 1`

#### Scenario: Дубликаты тегов
- **WHEN** в галерею добавляются теги `Tag:Tag 1` и `tag:tag 1`
- **THEN** галерея содержит один тег `tag:tag 1`

### Requirement: Известные типы тегов
Система SHALL определять известные типы тегов: `tag`, `artist`, `group`, `parody`, `character`, `language`, `category`. Тег неизвестного типа MUST сохраняться без изменений типа (после нормализации) и MUST NOT отбрасываться.

#### Scenario: Неизвестный тип
- **WHEN** создаётся тег с типом «Circle»
- **THEN** тег сохраняется с типом `circle` и помечается как неизвестный тип

### Requirement: Порядок страниц
Страницы галереи MUST упорядочиваться по имени файла в натуральном порядке (числовые фрагменты сравниваются как числа, без учёта регистра). Обложкой галереи MUST быть первая страница после упорядочивания.

#### Scenario: Числовые имена
- **WHEN** страницы называются `10.jpg`, `2.jpg`, `1.jpg`
- **THEN** порядок страниц: `1.jpg`, `2.jpg`, `10.jpg`, и обложка — `1.jpg`

#### Scenario: Галерея без страниц
- **WHEN** в галерее нет страниц
- **THEN** обложка отсутствует и запрос обложки возвращает признак отсутствия, без паники
