## ADDED Requirements

### Requirement: Фиксированная папка библиотеки
Приложение SHALL использовать одну фиксированную папку для хранения zip-архивов манги. Путь MUST определяться платформой и MUST NOT требовать выбора пользователем.

#### Scenario: Путь на Windows
- **WHEN** приложение запускается на Windows
- **THEN** папкой библиотеки является `<домашний каталог пользователя>\MangaReader\manga`

#### Scenario: Путь на Android
- **WHEN** приложение запускается на Android
- **THEN** папкой библиотеки является подкаталог `manga` во внешнем каталоге файлов приложения (`/storage/emulated/0/Android/data/<appID>/files/manga` или эквивалент), доступный для записи файлов с ПК по USB

### Requirement: Создание папки при старте
Приложение MUST создавать папку библиотеки (включая родительские каталоги), если она отсутствует, и MUST NOT изменять или удалять существующие в ней файлы.

#### Scenario: Первый запуск
- **WHEN** папка библиотеки не существует
- **THEN** приложение создаёт её, и она пуста

#### Scenario: Повторный запуск
- **WHEN** папка библиотеки уже существует и содержит файлы
- **THEN** приложение использует её без изменения содержимого

#### Scenario: Папку невозможно создать
- **WHEN** создание папки завершается ошибкой (нет прав, нет носителя)
- **THEN** приложение продолжает работу и показывает toast-уведомление с текстом ошибки и путём

### Requirement: Отображение пути библиотеки
Экран «Настройки» SHALL показывать полный путь к папке библиотеки, чтобы пользователь знал, куда копировать архивы.

#### Scenario: Просмотр пути
- **WHEN** пользователь открывает экран «Настройки»
- **THEN** отображается полный путь папки библиотеки для текущей платформы
