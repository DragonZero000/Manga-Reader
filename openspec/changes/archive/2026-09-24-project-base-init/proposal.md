## Why

MangaReader начинается с нуля (проект `nh whatcher` используется только как справочник, код не переносится). Нужен каркас, который собирается и запускается на ПК и Android и сразу закладывает модель данных и контракт поиска по параметрам произведения, чтобы последующие изменения (библиотека, читалка, поиск, API) не требовали переделки основы.

> Примечание: блокеры, перечисленные в `openspec/config.yaml` (`/api/v2`, rate limit, WebView, hardcoded key и т.д.), относятся к старому проекту `nh whatcher` и к этому изменению не применяются.

## What Changes

- Новый Go-модуль `mangareader` (Go 1.26, Fyne v2.8, `fyneDo = true`), точка входа `cmd/mangareader`, `FyneApp.toml`, Makefile со сборкой Windows `.exe` и Android `.apk`.
- Оболочка приложения: навигация между пустыми экранами (Библиотека, Поиск, Настройки) и слой уведомлений (toast), не заменяющий содержимое окна.
- Фиксированная папка библиотеки для каждой платформы (ПК: `~/MangaReader/manga`, Android: внешний каталог приложения `.../files/manga`), создаваемая при старте.
- Доменная модель: `Gallery`, `Page`, `Tag` с нормализацией, ключ галереи с префиксом источника (`local:<file>`).
- Модель запроса поиска по параметрам произведения (`Query`, `Filter`, `Field`, `Op`, `Sort`) и интерфейс `Index` без реализации.
- Спайк: сборка `modernc.org/sqlite` (с FTS5) в Android `.apk`; результат фиксируется в design.md и определяет реализацию `Index` в следующем изменении.

## Non-goals

- Сканирование папки, чтение zip и `meta.json`, сетка обложек (изменение `local-library`).
- Просмотр страниц и прогресс чтения (изменение `reader`).
- Реализация `Index`, парсер строки запроса, панель фильтров, подсказки тегов (изменение `search`).
- Сетевой API, авторизация, шифрование, скачивание, офлайн-кэш.
- Сборка под macOS/iOS/Linux (не запрещена, но не проверяется).

## Capabilities

### New Capabilities
- `app-shell`: запуск приложения, навигация между экранами, неблокирующие toast-уведомления, правило обновления UI из горутин.
- `library-location`: определение и создание фиксированной папки библиотеки на ПК и Android.
- `gallery-model`: единая модель произведения (галерея, страницы, типизированные теги) и правила нормализации.
- `search-query`: модель запроса по параметрам произведения и контракт индекса поиска.

## Impact

- Новый код: `cmd/mangareader`, `internal/app`, `internal/ui`, `internal/paths`, `internal/model`, `internal/search`.
- Зависимости: `fyne.io/fyne/v2 v2.8.x`; `modernc.org/sqlite` — только в спайке, в основной модуль не добавляется до решения.
- Инструменты: Go ≥ 1.26, `fyne` CLI и Android NDK для сборки `.apk`.
- `example.zip` переносится в `testdata/` как эталонный образец формата для следующих изменений.
