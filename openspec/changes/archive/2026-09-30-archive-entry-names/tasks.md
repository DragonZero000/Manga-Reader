## 2. Имена записей при разборе (design D2, D3)

- [x] 2.1 `entryPath(name)`: `\` → `/`, без пустых сегментов и `.`; `isServicePath`, базовое имя (`meta.json`, расширение) и `depth` работают по нему; `Page.Name`, сортировка и отпечаток — по сырому имени
- [x] 2.2 Повторяющиеся сырые имена страниц: первая запись — страница, остальные пропускаются с предупреждением `duplicate entry … skipped`; отпечаток по оставшимся страницам
- [x] 2.3 Тесты `ReadArchive` по сценариям «Разбор архива с meta.json»: `\` и `meta.json` в `ch1\`, `__MACOSX\`, Shift-JIS (имена страниц побайтно равны записям), `./` (галерея, а не «нет изображений»), повторы (2 страницы и предупреждение); отпечаток `testdata/example.zip` не изменился

## 3. Открытие страниц по записи оглавления (design D1)

- [x] 3.1 `findEntry(zr, name)` — первая запись-файл с точным именем; `Source.OpenPage` читает через `f.Open()` с прежним лимитом `maxPageSize`
- [x] 3.2 `Source.PageSizes`: карта «имя → первая запись» строится один раз; `pageSize` читает заголовок из `*zip.File`
- [x] 3.3 Тесты `OpenPage` и `PageSizes` для `ch1\001.jpg`, имени в Shift-JIS, `/001.jpg`, повторяющегося имени (байты первой записи); неизвестная страница — ошибка, как раньше

## 4. JSON страницы без потерь (design D4)

- [x] 4.1 `model.Page.MarshalJSON` / `UnmarshalJSON`: UTF-8 → `{"Name":…}` как сейчас, иначе `{"NameRaw":<base64>}`; чтение обоих видов
- [x] 4.2 Тесты `model`: круговой путь для UTF-8 и Shift-JIS имён; две разные не-UTF-8 строки остаются разными; старая запись `{"Name":"example/1.jpg"}` читается как раньше
- [x] 4.3 Тест `catalog`: галерея с Shift-JIS именами сохраняется через `ScanStore.Save` и загружается с побайтно равными именами; сценарий spec «Имена не в UTF-8 после перезапуска» — страницы галереи из каталога открываются через `Source`

## 5. Ревизия правил разбора (design D5)

- [x] 5.1 `library.ParseRevision = 1`; `ScanStore.ParseRevision()`; `ScanDelta.ParseRevision` и его учёт в `Empty()`; обновить тестовые `ScanStore` (`library/store_test.go` и др.)
- [x] 5.2 `catalog`: `meta.parse_rev` — чтение (нет значения → 0) и запись в транзакции `Save`; `Reset` его не трогает; тест чтения и записи
- [x] 5.3 Сканер: флаг `recheck` в `cacheEntry`, предикат ревизии 1 (`ErrNoImages`; страница с `\` или U+FFFD; повторяющиеся имена), `revPending`; `scanFile` не пропускает `recheck`; `Cached()` показывает такие записи; при занятом файле флаг сохраняется или наследуется ошибкой `BusyAsError`
- [x] 5.4 Конец `Scanner.Scan`: ревизия в дельте, только если записей с `recheck` не осталось; `revPending` сбрасывается после успешного `Save`
- [x] 5.5 Тесты по сценариям «Перепроверка после изменения правил разбора» (через `openHook` и `memStore`/каталог ревизии 0): открывается только затронутый архив; `./`-архив из ошибки «нет изображений» становится галереей (в `Added`); галерея с U+FFFD разбирается заново и её страницы открываются; после сохранения ревизии новый сканер ничего не открывает; занятый файл (подменённое хранилище с `ErrBusy`) — ревизия не сохраняется, файл перепроверяется в следующем скане; `Cached()` до скана содержит затронутую галерею
- [x] 5.6 Тест `userdata`/`app`: у архива с повторами после перепроверки отпечаток записи обновлён, `uid` прежний
