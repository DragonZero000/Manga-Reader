## Why

Каркас (`project-base-init`) создаёт папку библиотеки, но приложение не читает её содержимое: скопированные `.zip`-архивы не отображаются ни на ПК, ни на Android. Это первое изменение, после которого приложение показывает пользователю его мангу.

## What Changes

- Сканер папки библиотеки: находит `.zip`-архивы (включая вложенные папки), пропускает скрытые и не-zip файлы.
- Адаптер архива: `.zip` + `meta.json` → `model.Gallery`. `meta.json` и страницы ищутся на любой глубине внутри архива (в `example.zip` они лежат в корневой подпапке `example/`). Без `meta.json` галерея строится по имени файла.
- Повторное сканирование пропускает неизменённые архивы (сравнение размера и времени изменения).
- Источник `library.Source`: список галерей и открытие страницы по ключу — единая точка доступа к данным архива для UI (и будущей читалки).
- Миниатюры обложек: первая страница декодируется в фоне, уменьшается и кэшируется в памяти. Поддерживаются JPEG, PNG, GIF, WebP.
- Экран «Библиотека»: сетка карточек (обложка + название), счётчик, кнопка «Обновить», пустое состояние, отчёт о повреждённых архивах через toast.
- Автоматическое повторное сканирование при запуске и при возврате приложения на передний план (актуально после копирования архивов по USB на Android).
- Каждая найденная галерея передаётся в `search.Index.Upsert`; реализация индекса остаётся `NopIndex`.

## Non-goals

- Читалка: нажатие на карточку пока показывает только уведомление (изменение `reader`).
- Реализация индекса поиска и выбор SQLite / индекс в памяти (изменение `search`, решение по спайку S2 остаётся открытым).
- Дисковый кэш миниатюр, отслеживание изменений папки в реальном времени (fsnotify).
- Форматы, кроме `.zip`: `.cbz`, `.rar`, распакованные папки.
- Сортировка и фильтры в UI: порядок фиксирован — недавно добавленные сверху.
- Удаление, переименование и импорт архивов из приложения.

## Capabilities

### New Capabilities
- `library-scan`: обнаружение архивов в папке библиотеки, разбор `.zip` + `meta.json` в `Gallery`, инкрементальное повторное сканирование, обработка ошибок, открытие страниц.
- `library-view`: экран библиотеки — сетка с обложками, миниатюры, обновление, пустое состояние и ошибки.

## Impact

- Новый код: `internal/library` (scanner, archive, meta, source), `internal/thumbs`, переработка `internal/ui/screens/library.go`, подключение в `internal/app` и `internal/ui/shell.go`.
- Зависимости: `golang.org/x/image` (уже есть косвенно) — `webp` для декодирования, `draw` для масштабирования; становится прямой.
- Тестовые данные: `testdata/example.zip` плюс архивы, генерируемые в тестах (без `meta.json`, повреждённый, без картинок, с 10+ страницами).
- Зависит от `project-base-init` (модель `Gallery`, `paths`, оболочка, `Toast`).
