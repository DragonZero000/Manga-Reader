## ADDED Requirements

### Requirement: Список ошибок по состоянию папки
Приложение SHALL вести список ошибок библиотеки, построенный по результату последнего сканирования: по одной записи на каждый файл, который сканер не смог открыть как галерею. Запись MUST содержать путь относительно папки библиотеки, причину и время изменения файла. Идентичность записи MUST определяться тройкой «путь, размер, время изменения». Повторное сканирование MUST NOT создавать дубли уже известной записи. Запись MUST исчезать из списка, если файл удалён, перемещён или после изменения стал корректной галереей.

#### Scenario: Первая ошибка
- **WHEN** в папке появился `page.jpg` и библиотека просканирована
- **THEN** список ошибок содержит одну запись `page.jpg` с причиной «Изображение — поддерживаются только zip-архивы»

#### Scenario: Повторное сканирование без изменений
- **WHEN** папка с `page.jpg` сканируется ещё дважды
- **THEN** список по-прежнему содержит одну запись `page.jpg`

#### Scenario: Файл удалён
- **WHEN** пользователь удалил `page.jpg` и библиотека просканирована
- **THEN** записи `page.jpg` в списке нет

#### Scenario: Файл исправлен
- **WHEN** битый `broken.zip` заменён корректным архивом с тем же именем
- **THEN** записи `broken.zip` в списке нет, а галерея `broken.zip` появляется в библиотеке

### Requirement: Ошибочные файлы не удаляются
Приложение MUST NOT удалять, перемещать, переименовывать или изменять файлы, признанные ошибочными.

#### Scenario: Файл остаётся в папке
- **WHEN** сканирование признало `video.mp4` ошибочным
- **THEN** `video.mp4` остаётся в папке библиотеки без изменений

### Requirement: Статус просмотра
Каждая запись SHALL иметь статус «просмотрено» или «не просмотрено». Новая запись MUST появляться непросмотренной. Открытие вкладки «Ошибки» MUST отмечать просмотренными все записи; записи, появившиеся, пока вкладка открыта, MUST сразу считаться просмотренными. Статус MUST сохраняться между запусками приложения. Если файл изменился (другой размер или время изменения) и остался ошибочным, запись MUST считаться новой и непросмотренной. Сохранённые статусы файлов, которых больше нет в списке, MUST удаляться.

#### Scenario: Открытие вкладки
- **WHEN** есть 2 непросмотренные ошибки и пользователь открывает вкладку «Ошибки»
- **THEN** обе записи становятся просмотренными и остаются в списке

#### Scenario: Перезапуск
- **WHEN** пользователь просмотрел ошибку `page.jpg` и перезапустил приложение, файл не менялся
- **THEN** после сканирования запись `page.jpg` показывается просмотренной

#### Scenario: Файл перекачан и снова ошибочен
- **WHEN** просмотренный `g-1.zip` заменён другим файлом, который тоже не является архивом
- **THEN** запись `g-1.zip` снова непросмотренная

### Requirement: Вкладка «Ошибки»
Оболочка SHALL содержать вкладку «Ошибки» со списком записей: имя файла (путь относительно папки библиотеки), причина, время изменения. Непросмотренные записи MUST визуально выделяться (жирный шрифт и маркер). Порядок MUST быть: сначала более новые по времени изменения, при равенстве — по пути в натуральном порядке. Если ошибок нет, MUST показываться пустое состояние «Ошибок нет».

#### Scenario: Список ошибок
- **WHEN** в папке лежат ошибочные `a.jpg` (изменён вчера) и `b.mp4` (изменён сегодня)
- **THEN** вкладка показывает `b.mp4`, затем `a.jpg`, у каждой — причина и время

#### Scenario: Нет ошибок
- **WHEN** все файлы папки — корректные архивы
- **THEN** вкладка показывает «Ошибок нет»

### Requirement: Число непросмотренных ошибок на вкладке
Иконка вкладки «Ошибки» SHALL показывать число непросмотренных записей, если оно больше нуля; при числе больше 99 MUST показываться «99+». Если непросмотренных записей нет, число MUST NOT показываться. Число MUST обновляться после каждого сканирования и после открытия вкладки.

#### Scenario: Новые ошибки
- **WHEN** сканирование нашло 3 новых ошибочных файла, а вкладка «Ошибки» не открыта
- **THEN** на иконке вкладки показывается число 3

#### Scenario: Ошибки просмотрены
- **WHEN** пользователь открыл вкладку «Ошибки»
- **THEN** число на иконке исчезает

#### Scenario: Ошибка исчезла
- **WHEN** на иконке число 1, и пользователь удалил ошибочный файл, библиотека пересканирована
- **THEN** число на иконке исчезает
