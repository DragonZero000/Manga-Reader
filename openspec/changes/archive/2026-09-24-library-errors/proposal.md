## Why

Приложение молча пропускает всё в папке библиотеки, кроме `.zip`, а о битых архивах сообщает только toast «Не удалось прочитать архивов: N», который исчезает через 3 секунды. Пользователь не узнаёт, что скачанный файл оказался картинкой, видео или веб-страницей вместо архива. Встроенный браузер (изменение `embedded-browser`) будет сохранять файлы прямо в папку библиотеки — каждую неудачную загрузку нужно показать явно и не терять.

## What Changes

- **BREAKING (поведение сканера)**: сканер проверяет **все** файлы папки библиотеки, а не только `.zip`. Файл, который приложение не может открыть как галерею, становится ошибкой. Скрытые файлы (имя на `.`) по-прежнему пропускаются.
- Незавершённые загрузки не считаются ошибками: файлы `*.part` и пустой файл, рядом с которым лежит `<имя>.part`, пропускаются.
- Тип неподдерживаемого файла определяется по содержимому (сигнатуре), а не по расширению: изображение, видео, аудио, веб-страница (HTML), PDF, другой архив (rar/7z), текст, неизвестный формат. Сообщение называет тип, например «Изображение — поддерживаются только zip-архивы».
- Новая вкладка «Ошибки»: список файлов с ошибками (путь, причина, время изменения), новые — выделены.
- Список строится по текущему состоянию папки: одна ошибка на файл, без дублей; ошибка исчезает, когда файл удалён или исправлен (заменён корректным).
- Статус «просмотрено»: открытие вкладки отмечает все ошибки просмотренными. Статус переживает перезапуск; если файл изменился и снова ошибочен — это новая, непросмотренная ошибка.
- Число непросмотренных ошибок показывается на иконке вкладки.
- Приложение **никогда не удаляет и не перемещает** ошибочные файлы.
- Toast после сканирования сообщает о новых ошибках и ссылается на вкладку.

## Non-goals

- Удаление, переименование, открытие файла из вкладки «Ошибки».
- Поддержка новых форматов (cbz, rar, pdf, папки с картинками).
- Отдельный статус для предупреждений (некорректный `meta.json`) — они по-прежнему только в журнале.
- Автоматическое обнаружение новых файлов (изменение `library-watch`).

## Capabilities

### New Capabilities
- `library-errors`: вкладка «Ошибки», модель ошибок по состоянию папки, статус просмотра, бейдж с числом непросмотренных.

### Modified Capabilities
- `library-scan`: проверяются все файлы, классификация неподдерживаемых файлов по содержимому, пропуск незавершённых загрузок.
- `library-view`: toast о повреждённых архивах заменяется сообщением о новых ошибках со ссылкой на вкладку.
- `app-shell`: в навигацию добавляется экран «Ошибки».

## Impact

- `internal/library/scanner.go`, `archive.go`: обход всех файлов, классификация (`sniff.go`), размер и время файла в `ScanError`.
- Новый пакет `internal/problems` (без виджетов): список ошибок, статус просмотра, сохранение в настройках. Добавляется в `archtest`.
- Новый экран `internal/ui/screens/errors.go`, иконка с числом; `internal/ui/shell.go` — вкладка и связь с библиотекой.
- Хранение: одна настройка (`errors.state`) через существующий `storage.Settings` — `settings.json` на ПК, Preferences на Android.
- Зависимости не добавляются (`net/http.DetectContentType` из stdlib).
