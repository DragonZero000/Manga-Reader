## MODIFIED Requirements

### Requirement: Справка при пустом запросе
До первого выполненного за сессию запроса экран SHALL показывать краткую справку по синтаксису с примерами: поиск по слову, фраза в кавычках, `tag:`, `artist:`, исключение `-tag:`, свой тег `custom-tag:`, скрытый тег `hidden-tag:`, `pages:>20`, `uploaded:2024`, `size:>10mb`. После первого выполненного запроса справка MUST NOT показываться до конца сессии: на экране MUST оставаться последний результат, в том числе при пустом поле.

#### Scenario: Пустой запрос
- **WHEN** пользователь впервые за сессию открывает вкладку «Поиск» с пустым полем
- **THEN** показывается справка с примерами запросов, среди них `custom-tag:` и `hidden-tag:`

#### Scenario: После запроса справки нет
- **WHEN** выполнен запрос `english`, затем пользователь очищает поле (кнопкой ✕ или вручную), уходит на другую вкладку и возвращается
- **THEN** справка не показывается, на экране результаты для `english`
