## MODIFIED Requirements

### Requirement: Совпадение слов
Слово или фраза свободного текста SHALL совпадать с произведением, если оно входит как подстрока хотя бы в одно из полей: основное название, альтернативное название, имя любого действующего тега (оригинальные без скрытых плюс свои), тип и имя действующего тега в форме `тип:имя`, сканлейтор, путь файла относительно библиотеки, внешний ID. Скрытые теги MUST NOT участвовать в совпадении слов. Сравнение MUST выполняться после одинаковой нормализации поля и запроса: совместимая декомпозиция Unicode (NFKC), нижний регистр, `ё` → `е`. Если в запросе несколько слов, произведение MUST содержать каждое из них (в одном или разных полях).

#### Scenario: Часть слова в названии
- **WHEN** выполняется поиск `glis`
- **THEN** находится `example.zip` (название «english name»)

#### Scenario: Часть слова в теге
- **WHEN** выполняется поиск `japan`
- **THEN** находится `example.zip` (тег `language:japanese` и название «japanease name»)

#### Scenario: Слова в разных полях
- **WHEN** выполняется поиск `english doujin`
- **THEN** находится `example.zip`: «english» в названии, «doujin» в теге `category:doujinshi`

#### Scenario: Нет совпадения одного слова
- **WHEN** выполняется поиск `english manhwa`
- **THEN** `example.zip` не находится

#### Scenario: Кириллица и ё
- **WHEN** у произведения название «Ёлка», и выполняются поиски `ёлка`, `ЕЛКА` и `елк`
- **THEN** произведение находится каждым из них

#### Scenario: Полноширинные символы
- **WHEN** у произведения название «ABC», и выполняется поиск `ＡＢＣ`
- **THEN** произведение находится

#### Scenario: Скрытый тег не находится словом
- **WHEN** у `example.zip` скрыт `category:doujinshi`, и выполняется поиск `doujin`
- **THEN** `example.zip` не находится

#### Scenario: Свой тег находится словом
- **WHEN** у `example.zip` есть свой тег `character:alice`, и выполняется поиск `alic`
- **THEN** `example.zip` находится

### Requirement: Совпадение условий
Фильтры запроса SHALL проверяться так: тег («есть»/«нет») — точное совпадение нормализованного имени, а если тип указан — и типа; область тегов зависит от поля: `tag` и поля типов — действующие теги (оригинальные без скрытых плюс свои), `custom-tag` — только свои, `hidden-tag` — только скрытые оригинальные. `title` — подстрока в основном или альтернативном названии; `scanlator` — подстрока (операция «содержит») или точное совпадение («равно»). Текстовые значения (имена тегов, `title`, `scanlator`) MUST сравниваться после той же нормализации, что и слова (NFKC, нижний регистр, `ё` → `е`). `pages` — по фактическому числу страниц; `favorites`, `id` — по значениям метаданных; `size` — по размеру файла; `uploaded` — по дате загрузки; `added` — по времени изменения файла. Произведение без значения поля (ноль, нулевая дата) MUST NOT удовлетворять числовым и датовым фильтрам по этому полю.

#### Scenario: Тег любого типа
- **WHEN** выполняется поиск `tag:japanese`
- **THEN** находится `example.zip` (тег `language:japanese`)

#### Scenario: Тег точного типа
- **WHEN** выполняется поиск `artist:japanese`
- **THEN** `example.zip` не находится

#### Scenario: Подстрока не совпадает с тегом
- **WHEN** выполняется поиск `tag:japan`
- **THEN** `example.zip` не находится: для тега нужно точное имя

#### Scenario: Исключение
- **WHEN** выполняется поиск `english -tag:"tag 3"`
- **THEN** `example.zip` не находится

#### Scenario: Число страниц
- **WHEN** выполняются поиски `pages:2` и `pages:>2`
- **THEN** `example.zip` находится первым поиском и не находится вторым

#### Scenario: Нет значения
- **WHEN** архив без `meta.json` и выполняется поиск `favorites:<10`
- **THEN** этот архив не находится

#### Scenario: Тег с ё
- **WHEN** у произведения тег `tag:ёжик`, и выполняется поиск `tag:ежик`
- **THEN** произведение находится

#### Scenario: Скрытый тег
- **WHEN** у `example.zip` скрыт `tag:tag 3`
- **THEN** поиск `tag:"tag 3"` не находит `example.zip`, `-tag:"tag 3"` и `hidden-tag:"tag 3"` находят его

#### Scenario: Свой тег
- **WHEN** у `example.zip` есть свой тег `character:alice`
- **THEN** его находят `character:alice`, `tag:alice` и `custom-tag:alice`; `custom-tag:"tag 1"` его не находит

### Requirement: Подсказки тегов
Индекс SHALL возвращать действующие теги (оригинальные без скрытых плюс свои), имя которых начинается с заданного префикса (без учёта регистра), с числом произведений для каждого тега, отсортированные по убыванию числа, затем по имени; при заданном типе — только теги этого типа; не более заданного лимита.

#### Scenario: Подсказка по префиксу
- **WHEN** запрашиваются подсказки для префикса `tag` без типа с лимитом 10
- **THEN** возвращаются `tag:tag 1`, `tag:tag 2`, `tag:tag 3` с числом 1 у каждого

#### Scenario: Свой тег в подсказках
- **WHEN** у одного произведения есть свой тег `character:alice`, и запрашиваются подсказки для `ali` типа `character`
- **THEN** возвращается `character:alice` с числом 1
