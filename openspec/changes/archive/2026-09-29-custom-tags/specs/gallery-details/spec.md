## MODIFIED Requirements

### Requirement: Теги по типам
Теги SHALL показываться группами по типам в фиксированном порядке: «Автор» (`artist`), «Группа» (`group`), «Пародия» (`parody`), «Персонаж» (`character`), «Язык» (`language`), «Категория» (`category`), «Теги» (`tag`), затем группы неизвестных типов в алфавитном порядке с названием типа. Показываются действующие теги (см. `custom-tags`): оригинальные теги без скрытых и свои теги. Внутри группы оригинальные теги MUST идти в порядке из `meta.json`, за ними — свои в порядке добавления; теги MUST переноситься по строкам по ширине экрана. Свои теги MUST выделяться жёлтым так, чтобы текст оставался читаемым в светлой и тёмной теме. Скрытые теги вне режима редактирования MUST NOT показываться. Группы без видимых тегов MUST NOT показываться; если видимых тегов нет совсем, вне режима редактирования раздел MUST содержать только кнопку «Изменить тэги». Нажатие на тег (оригинальный или свой) вне режима редактирования MUST открывать поиск по этому тегу: для известного типа — `тип:"имя"`, для неизвестного — `tag:"имя"`.

#### Scenario: Группировка
- **WHEN** открывается страница `example.zip` без своих и скрытых тегов
- **THEN** показываются группы «Автор: artist 1», «Пародия: parody 1», «Персонаж: character 1», «Язык: japanese», «Категория: doujinshi», «Теги: tag 1, tag 2, tag 3» в этом порядке

#### Scenario: Неизвестный тип
- **WHEN** у произведения есть тег типа `circle`
- **THEN** он показывается в отдельной группе «circle» после известных групп

#### Scenario: Нет тегов
- **WHEN** архив без `meta.json` и без своих тегов
- **THEN** групп тегов нет, показывается только кнопка «Изменить тэги»

#### Scenario: Нажатие на тег
- **WHEN** пользователь нажимает на тег «artist 1» в группе «Автор»
- **THEN** открывается вкладка «Поиск» с запросом `artist:"artist 1"` и результатами

#### Scenario: Свой тег
- **WHEN** у `example.zip` есть свой тег `character:alice`
- **THEN** в группе «Персонаж» после `character 1` показан жёлтый `alice`; нажатие открывает поиск `character:"alice"`

#### Scenario: Скрытый тег
- **WHEN** у `example.zip` скрыт `tag:tag 2`
- **THEN** группа «Теги» показывает `tag 1, tag 3`
