## MODIFIED Requirements

### Requirement: Ввод и выполнение запроса
Экран «Поиск» SHALL содержать поле запроса. Когда выполняется запрос, зависит от режима поиска (см. «Режим поиска»):
- **«При вводе»**: запрос MUST выполняться через 500 мс после последнего изменения текста. Каждое изменение MUST перезапускать отсчёт. Кнопка 🔍 MUST быть скрыта. Enter MUST только убирать фокус с поля (на Android — закрывать клавиатуру) и не запускать запрос, отсчёт при этом продолжается. Результаты MUST показываться, даже если клавиатура открыта.
- **«По кнопке»**: изменение текста MUST NOT запускать запрос. Запрос MUST выполняться по нажатию кнопки 🔍 или Enter.

Если в момент выполнения поле пустое (только пробелы), запрос MUST NOT выполняться, а на экране MUST оставаться прежнее состояние. Поиск MUST выполняться в фоне, результаты MUST применяться через основной поток. Результат устаревшего запроса (после него выполнен другой) MUST отбрасываться.

#### Scenario: Поиск по мере ввода
- **WHEN** в режиме «При вводе» пользователь вводит `english` и 500 мс не печатает
- **THEN** показываются результаты для `english` без нажатия Enter

#### Scenario: Пауза меньше задержки
- **WHEN** в режиме «При вводе» пользователь вводит `ком`, через 300 мс дописывает `икс` и затем 500 мс не печатает
- **THEN** запрос `ком` не выполняется, показываются результаты для `комикс`

#### Scenario: Быстрый ввод
- **WHEN** в режиме «При вводе» пользователь быстро вводит `eng`, затем `english`
- **THEN** на экране результаты для `english`, а не для `eng`

#### Scenario: Enter при вводе
- **WHEN** в режиме «При вводе» пользователь вводит `english` и сразу нажимает Enter
- **THEN** запрос сразу не выполняется, фокус с поля снимается, а результаты для `english` появляются через 500 мс после ввода

#### Scenario: Кнопка скрыта при вводе
- **WHEN** выбран режим «При вводе»
- **THEN** кнопки 🔍 у поля нет

#### Scenario: Ввод в режиме «По кнопке»
- **WHEN** в режиме «По кнопке» пользователь вводит `english` и ждёт больше 500 мс
- **THEN** запрос не выполняется, на экране прежнее состояние

#### Scenario: Запуск кнопкой
- **WHEN** в режиме «По кнопке» пользователь вводит `english` и нажимает 🔍 или Enter
- **THEN** сразу выполняется запрос `english`

#### Scenario: Пустое поле
- **WHEN** выполнен запрос `english`, затем пользователь стирает текст вручную и 500 мс не печатает (режим «При вводе») или нажимает 🔍 (режим «По кнопке»)
- **THEN** запрос не выполняется, на экране остаются результаты для `english`

### Requirement: Ошибки запроса
Если строку запроса не удалось разобрать при попытке выполнить запрос (по истечении задержки в режиме «При вводе» или по кнопке либо Enter в режиме «По кнопке»), под полем ввода SHALL показываться сообщение об ошибке с проблемным фрагментом. Предыдущие результаты MUST оставаться на экране до исправления запроса. Пока запрос не выполняется, ошибка MUST NOT показываться.

#### Scenario: Ошибка
- **WHEN** пользователь вводит `pages:>много` и запрос выполняется
- **THEN** под полем показывается сообщение об ошибке, указывающее на `pages:>много`

#### Scenario: Ошибка не показывается до выполнения
- **WHEN** в режиме «По кнопке» пользователь вводит `pages:>много` и не нажимает 🔍
- **THEN** сообщения об ошибке нет

### Requirement: Справка при пустом запросе
До первого выполненного за сессию запроса экран SHALL показывать краткую справку по синтаксису с примерами: поиск по слову, фраза в кавычках, `tag:`, `artist:`, исключение `-tag:`, `pages:>20`, `uploaded:2024`, `size:>10mb`. После первого выполненного запроса справка MUST NOT показываться до конца сессии: на экране MUST оставаться последний результат, в том числе при пустом поле.

#### Scenario: Пустой запрос
- **WHEN** пользователь впервые за сессию открывает вкладку «Поиск» с пустым полем
- **THEN** показывается справка с примерами запросов

#### Scenario: После запроса справки нет
- **WHEN** выполнен запрос `english`, затем пользователь очищает поле (кнопкой ✕ или вручную), уходит на другую вкладку и возвращается
- **THEN** справка не показывается, на экране результаты для `english`

### Requirement: Поиск с другого экрана
Приложение SHALL позволять открыть вкладку «Поиск» с заданным текстом запроса: открытые слои (страница произведения) закрываются, поле заполняется, запрос выполняется сразу в любом режиме. Заполнение поля MUST NOT приводить к повторному выполнению того же запроса по таймеру режима «При вводе».

#### Scenario: Переход из страницы произведения
- **WHEN** вызывается поиск по тексту `artist:"artist 1"`
- **THEN** страница произведения закрывается, открывается вкладка «Поиск» с этим текстом и результатами

#### Scenario: Без повторного запроса
- **WHEN** в режиме «При вводе» вызывается поиск по тексту `artist:"artist 1"` и проходит больше 500 мс
- **THEN** запрос `artist:"artist 1"` выполнен один раз

### Requirement: Актуальность результатов
При каждом открытии вкладки «Поиск» и после каждого сканирования библиотеки SHALL заново выполняться последний выполненный запрос, а не текущий текст поля, чтобы результаты отражали содержимое папки. Если за сессию запрос ещё не выполнялся, MUST оставаться справка.

#### Scenario: Новый архив
- **WHEN** в папку добавлен подходящий архив, библиотека пересканирована, а пользователь возвращается на вкладку «Поиск»
- **THEN** новый архив есть в результатах

#### Scenario: Неотправленный текст не выполняется
- **WHEN** в режиме «По кнопке» выполнен запрос `english`, затем пользователь вводит `japan` без нажатия 🔍 и библиотека пересканирована
- **THEN** заново выполняется `english`, в поле остаётся `japan`

## ADDED Requirements

### Requirement: Режим поиска
Экран «Настройки» SHALL содержать раздел «Поиск» с выбором режима: «При вводе» и «По кнопке». По умолчанию MUST быть выбран «При вводе». Выбор MUST сохраняться в настройках и восстанавливаться при следующем запуске. Смена режима MUST применяться к экрану «Поиск» сразу: показать или скрыть кнопку 🔍 и отменить ожидающий запрос.

#### Scenario: Режим по умолчанию
- **WHEN** приложение запускается впервые
- **THEN** в настройках выбран режим «При вводе»

#### Scenario: Сохранение выбора
- **WHEN** пользователь выбирает «По кнопке» и перезапускает приложение
- **THEN** выбран режим «По кнопке», у поля поиска есть кнопка 🔍

#### Scenario: Смена режима отменяет ожидание
- **WHEN** в режиме «При вводе» пользователь вводит `english` и до истечения 500 мс переключает режим на «По кнопке»
- **THEN** запрос `english` не выполняется

### Requirement: Сброс поля поиска
Рядом с полем запроса SHALL быть кнопка ✕ в обоих режимах. Нажатие MUST очищать поле и отменять ожидающий запрос. Результаты и строка статуса на экране MUST NOT меняться.

#### Scenario: Сброс сохраняет результаты
- **WHEN** выполнен запрос `english`, и пользователь нажимает ✕
- **THEN** поле пустое, на экране остаются «Найдено: 1» и результаты для `english`

#### Scenario: Сброс отменяет ожидание
- **WHEN** в режиме «При вводе» пользователь вводит `japan` и до истечения 500 мс нажимает ✕
- **THEN** запрос `japan` не выполняется
