## Context

- `tools/fetch-firefox` скачивает `win64/ru/Firefox Setup 153.3.0esr.exe` с закреплённой SHA-256 и распаковывает в `browser\firefox\`.
- Профиль настраивается через `user.js` (`internal/browser/config.go`), который записывается при каждом запуске; встроенное расширение копируется в `profile\extensions\` (`extension.go`), автоустановка разрешена (`extensions.autoDisableScopes = 0`, `enabledScopes = 15`, `xpinstall.signatures.required = false` на ESR).
- Язык приложения определяется в `i18n-english` (`i18n.Lang()`).

## Goals / Non-Goals

**Goals:**
- Интерфейс Firefox на языке приложения; непереведённое — на английском.
- Язык страниц как в обычном Firefox.
- Добавление языка = строка в списке пакетов `fetch-firefox` + `_locales/<язык>` расширения.

**Non-Goals:**
- Словари проверки орфографии (в `en-US` встроен английский; русский словарь — возможное отдельное изменение).
- Перевод отдельных exe Firefox (`crashreporter.exe`, служба обновлений).
- Набор поисковиков по умолчанию.
- Android (`i18n-english`).

## Decisions

**База `en-US` + языковые пакеты, а не `ru` + пакеты и не несколько сборок.** `en-US` — исходный язык: любая строка, отсутствующая в пакете, покажется по-английски, что совпадает с правилом приложения «по умолчанию English». Несколько полных сборок — по ~180 МБ на язык.

```
fetch-firefox
  ├─ win64/en-US/Firefox Setup <ver>.exe      sha из SHA256SUMS
  └─ win64/xpi/ru.xpi                         sha из SHA256SUMS
        └─► browser\firefox\langpacks\ru.xpi

запуск браузера (язык приложения L)
  ├─ L ≠ en и есть langpacks\L.xpi → копировать в profile\extensions\langpack-L@firefox.mozilla.org.xpi
  ├─ пакеты других языков в профиле остаются (не мешают, переключение без повторной установки)
  └─ user.js: user_pref("intl.locale.requested", "<L или en-US>")
```

Id пакета берётся из его `manifest.json` при сборке (`langpack-ru@firefox.mozilla.org`) и сохраняется рядом (или читается при установке), чтобы имя файла в `extensions` совпадало с id — как для встроенного расширения.

`extensions.startupScanScopes = 1` (папка профиля проверяется при запуске): без него существующий профиль подхватывает новый пакет уже после старта, и первый запуск после обновления идёт на English (найдено при проверке 4.2).

Альтернатива — `browser\firefox\distribution\extensions\` (установка для всех профилей): проще, но пакет устанавливается один раз при первом запуске профиля, и добавление языка в следующей версии приложения не подхватится существующим профилем.

**`intl.accept_languages` не пишется.** В Firefox значение по умолчанию берётся из `intl.properties` текущего языка интерфейса; пользовательское значение хранится в `prefs.js`. Если приложение запишет его в `user.js`, выбор пользователя будет затираться при каждом запуске.

**Расширение MangaReader.** `manifest.json`: `"default_locale": "en"`, `"name": "__MSG_extName__"`, `"description": "__MSG_extDescription__"`, `"default_title": "__MSG_actionTitle__"`; файлы `_locales/en/messages.json`, `_locales/ru/messages.json`. Firefox выбирает язык сообщений по языку своего интерфейса — совпадает с языковым пакетом автоматически. Тексты расширения — не часть `internal/i18n`, но тест полноты `_locales` (одинаковые ключи) добавляется к тестам `internal/browser`.

**Существующие профили.** Профиль, созданный русской сборкой, открывается сборкой `en-US` без миграции: закладки, cookies, расширения, `search.json.mozlz4` не зависят от языка сборки.

## Risks / Trade-offs

- [Версия пакета не совпадает с ESR после обновления Firefox → Firefox отключает пакет, интерфейс на английском] → версия и суммы пакетов обновляются вместе с версией ESR в одном месте (`fetch-firefox`), комментарий в коде.
- [Поисковик по умолчанию может смениться при смене базовой сборки] → выбор пользователя хранится в профиле; проверить на существующем профиле при переходе.
- [Словарь проверки орфографии русской сборки пропадёт] → отмечено в release notes; словарь — отдельным изменением при необходимости.
- [Отчёт о сбое и системные окна не на языке приложения] → приемлемо, отмечено в non-goals.
- [Размер] → +≈ 0,5 МБ на каждый язык кроме English; сборки `en-US` и `ru` одинаковы по размеру.

## Platforms

Только Windows (`internal/browser` — Windows-код и `stub_other.go`; `tools/fetch-firefox` работает только на Windows). На Android браузер не затрагивается; на Linux (в планах) браузера пока нет.

## Migration Plan

1. `fetch-firefox` скачивает новую базу и пакеты в `browser\.cache` и перезаписывает `browser\firefox\`.
2. Первый запуск браузера после обновления: пакет копируется в профиль, `user.js` задаёт язык.
3. Откат: предыдущая версия с русской сборкой проигнорирует `intl.locale.requested` для отсутствующего языка — профиль продолжит работать.
