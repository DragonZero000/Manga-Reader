## ADDED Requirements

### Requirement: Перечисление архивов через хранилище
Хранилище библиотеки SHALL перечислять все файлы в папке библиотеки и её подпапках с относительным путём (прямые слеши), размером в байтах и временем изменения. Правила отбора архивов (расширение `.zip` без учёта регистра, пропуск имён на `.`) MUST быть одинаковыми на ПК и Android.

#### Scenario: Вложенная папка на Android
- **WHEN** в выбранной папке `Download/manga` лежит `series/vol1.zip`
- **THEN** сканер получает элемент с путём `series/vol1.zip`, его размером и временем изменения, и галерея получает ключ `local:series/vol1.zip`

#### Scenario: Файл, сохранённый браузером
- **WHEN** браузер сохранил `a.zip` в выбранную папку
- **THEN** архив появляется в библиотеке после сканирования

### Requirement: Открытие архива для чтения
Хранилище SHALL открывать файл для чтения с произвольным доступом (для разбора zip) и сообщать его размер. На Android файл MUST открываться через дескриптор, выданный системой для документа выбранной папки, без копирования всего архива. Открытый файл MUST закрываться после чтения, чтобы не удерживать дескрипторы.

#### Scenario: Чтение zip на Android
- **WHEN** открывается страница архива из выбранной папки на Android
- **THEN** страница читается и отображается, как на ПК

#### Scenario: Файл исчез
- **WHEN** архив удалён после сканирования и открывается его страница
- **THEN** возвращается ошибка, приложение не завершается аварийно

### Requirement: Недоступное хранилище
Если папка библиотеки недоступна (Android: папка не выбрана, разрешение отозвано или папка удалена; ПК: папку не удалось создать), сканирование SHALL завершаться ошибкой вида «хранилище недоступно» с причиной, которую UI использует для показа экрана выбора папки (Android) или toast (ПК).

#### Scenario: Разрешение отозвано
- **WHEN** пользователь отозвал доступ приложения к папке в настройках Android
- **THEN** сканирование возвращает ошибку недоступного хранилища, и показывается экран выбора папки

### Requirement: Настройки приложения
Приложение SHALL хранить настройки (режим читалки; на Android — выбранную папку) через общий интерфейс настроек: на ПК — в файле `settings.json` в папке приложения (JSON-объект «ключ — строка»), на Android — в хранилище настроек Fyne. Повреждённый или отсутствующий `settings.json` MUST приводить к значениям по умолчанию без ошибки запуска.

#### Scenario: Сохранение режима на ПК
- **WHEN** пользователь выбирает режим «Лента» и перезапускает приложение
- **THEN** `settings.json` содержит `"reader.mode": "strip"`, и читалка открывается в режиме ленты

#### Scenario: Повреждённый файл
- **WHEN** `settings.json` содержит некорректный JSON
- **THEN** приложение запускается с настройками по умолчанию и перезаписывает файл при следующем изменении настройки
