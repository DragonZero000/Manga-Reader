## Why

Сейчас папка библиотеки фиксирована и неудобна: на ПК — `%USERPROFILE%\MangaReader\manga`, а настройки Fyne пишутся в `%APPDATA%`, то есть приложение «размазано» по системе; на Android — `Android/data/<app>/files/manga`, куда с Android 11 не попасть обычным файловым менеджером и которая удаляется вместе с приложением. Пользователь хочет портативную ПК-версию (всё в папке приложения) и на Android — папку в `Download`, куда можно складывать файлы из браузера и файлового менеджера.

## What Changes

- **ПК — портативный режим:** всё хранится в папке приложения (каталог исполняемого файла; при `go run` — рабочая папка): архивы в `<папка>\manga`, настройки в `<папка>\settings.json`. Приложение больше ничего не пишет вне этой папки: на ПК оно создаётся без ID Fyne, поэтому Fyne не сохраняет `preferences.json` в `%APPDATA%`.
- **Android — папка, выбранная пользователем** (Storage Access Framework): при первом запуске открывается системный выбор папки (например, `Download/manga`, её можно создать в диалоге); разрешение сохраняется между запусками; приложение читает все файлы в папке и подпапках независимо от того, кто их туда положил (браузер, файловый менеджер, USB). Особые разрешения («доступ ко всем файлам») не нужны.
- Экран «Выберите папку с мангой» с кнопкой — если выбор отменён, разрешение потеряно или папка удалена. В «Настройках» — выбранная папка и кнопка «Изменить папку» (Android).
- **BREAKING (Android):** прежняя папка `Android/data/<app>/files/manga` больше не используется; архивы оттуда нужно перенести вручную. Код для неё (JNI `getExternalFilesDir`, `chmod`) удаляется.
- **BREAKING (ПК):** прежняя папка `%USERPROFILE%\MangaReader\manga` больше не используется; архивы нужно перенести в папку `manga` рядом с `mangareader.exe`.
- Внутри библиотеки появляется прослойка хранилища (список файлов, открытие для чтения): на ПК — обычная файловая система, на Android — SAF через JNI. Разбор архивов, читалка, поиск не меняются.
- Настройки (режим читалки, на Android — выбранная папка) — через общий интерфейс: на ПК файл `settings.json`, на Android — хранилище настроек Fyne.

## Non-goals

- Автоматический перенос архивов из старых папок.
- Доступ к корню `Download` на Android 11+ (система запрещает выбирать его) и режим «доступ ко всем файлам».
- Выбор папки пользователем на ПК (папка фиксирована — `manga` у исполняемого файла).
- Несколько папок библиотеки одновременно.
- Запись в папку библиотеки на Android (приложение только читает).

## Capabilities

### New Capabilities
- `library-storage`: доступ к файлам библиотеки через хранилище — перечисление архивов с размером и датой, открытие архива для чтения на ПК и через SAF на Android, сохранение разрешения, настройки приложения.

### Modified Capabilities
- `library-location`: папка библиотеки — рядом с исполняемым файлом на ПК и выбранная пользователем папка на Android вместо фиксированных путей; создание папки только на ПК; экран выбора папки; отображение и смена папки в «Настройках».
- `library-view`: пустое состояние на Android предлагает выбрать папку, если она не выбрана или недоступна.

## Impact

- Код: новый пакет `internal/storage` (интерфейс, `fsStorage`, `safStorage` с JNI, настройки); переработка `internal/paths` (папка приложения, удаление `Android/data`-кода); `internal/library` (сканер и чтение через хранилище вместо путей); `internal/app` (выбор хранилища); `cmd/mangareader/main.go` (приложение без ID на ПК); `internal/ui/reader` (настройки через интерфейс); `internal/ui/screens` (экран выбора папки, «Настройки»).
- Сборка: `FyneApp.toml` на ПК больше не определяет ID приложения при `go run` (метаданные задаются кодом); Android-манифест не меняется (новых разрешений нет).
- Данные пользователей: архивы из старых папок нужно перенести (см. BREAKING).
