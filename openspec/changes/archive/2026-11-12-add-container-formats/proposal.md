## Why

Библиотека принимает только файлы с расширением `.zip`. Манга в формате `.cbz` (тот же zip с другим расширением) и `.cbr`/`.cb7` (RAR/7z) отклоняется как ошибка, хотя это самые распространённые форматы комиксов. В `.cbz` часто лежит `ComicInfo.xml` вместо `meta.json` или вместе с ним, и сейчас эти данные теряются.

## What Changes

- Тип файла определяется по содержимому, а не по расширению: zip с любым расширением (`.cbz`, `.cbt` и т. д.) открывается как архив. Сообщение «zip с другим расширением» исчезает.
- Читается `ComicInfo.xml` (Anansi Project): поля заполняют галерею, если их нет в `meta.json`. При конфликте приоритет у `meta.json`.
  - `Title` (иначе `Series` + `Number`) → название; `AlternateSeries` → японское название; `Tags` (через запятую) → `tag`; `Characters` → `character`; `LanguageISO` → `language`; `Format` → `category`; `Writer`/`Penciller` → `artist`; `Publisher` → `group`; `Year`/`Month`/`Day` → дата; `PageCount` → число страниц; `Web` → ссылка на работу, только если в адресе есть путь.
  - `Manga` и `AgeRating` игнорируются.
- **Этап с решением пользователя:** поддержка RAR (`.rar`, `.cbr`) и 7z (`.7z`, `.cb7`). Сначала проверяется сборка библиотек `nwaples/rardecode` (BSD-2) и `bodgit/sevenzip` (BSD-3) под Windows и Android и прирост размера; брать ли каждую, решает пользователь по результату. Solid-архивы читаются через временный кэш ограниченного размера.
- Документация (en/ru) описывает новые форматы; в `THIRD_PARTY_NOTICES.md` добавляются подключённые библиотеки (`golang-lru` под MPL-2.0 как зависимость `sevenzip`).

Платформы: Windows и Android ведут себя одинаково; Linux пока не поддерживается.

### Non-goals

- PDF, EPUB, AVIF/JXL/HEIC, папки с картинками как галереи.
- Направление чтения из `Manga: YesAndRightToLeft` и возрастной рейтинг.
- Замена подчёркиваний в названии из имени файла.
- Скачивание в браузере с MangaLib и Remanga (поведение сайтов).

## Capabilities

### New Capabilities
- `comicinfo-metadata`: чтение `ComicInfo.xml` из архива и перенос полей в модель галереи, приоритет `meta.json`.

### Modified Capabilities
- `library-scan`: файл распознаётся как архив по содержимому, а не по расширению `.zip`; однократная перепроверка файлов, ранее отклонённых по расширению; поддерживаются RAR и 7z (после решения пользователя).
- `documentation`: описание форматов и таблица «Откуда брать файлы».

## Impact

- Код: `internal/library` (`scanner.go`, `archive.go`, `sniff.go`, новый разбор `ComicInfo.xml`), `internal/model` (при необходимости), тесты и `testdata/cbz-example.cbz`.
- Зависимости: `go.mod` (`rardecode/v2`, `sevenzip` и их зависимости) — только после решения; `THIRD_PARTY_NOTICES.md`.
- Каталог `library.db`: ключ галереи строится из пути, так что `.cbz`-файлы получают новые записи без миграции; требуется проверка, что повторное сканирование не дублирует записи.
- Документация: `docs/en`, `docs/ru`, `README.md`, `README.ru.md`.
