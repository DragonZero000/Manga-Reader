## Why

Библиотека показывает архивы, но открыть их нельзя: нажатие на карточку выводит только toast. Читалка — основная функция приложения; все данные для неё уже есть (`library.Source.OpenPage`).

## What Changes

- Читалка — полноэкранный слой поверх вкладок (вкладки под ним сохраняют состояние). Открывается нажатием на карточку, всегда с первой страницы.
- Постраничный режим, западный порядок (слева направо): тап-зоны «назад / панель / вперёд», свайп, клавиши ← → PgUp PgDn Home End и колесо мыши на ПК. Страница вписана в экран; двойной тап — увеличение ×2 в точке тапа, перетаскивание увеличенной страницы, повторный двойной тап — возврат.
- Режим ленты (вебтун): страницы подряд по ширине экрана, прокрутка пальцем/колесом, виртуализированный список. Высоты строк вычисляются по размерам страниц из заголовков изображений; страницы выше 2048 px после масштабирования режутся на куски (ограничение размера текстуры GPU).
- Панель управления по тапу в центр: название, номер страницы, ползунок перехода, переключатель режима, кнопка «Закрыть».
- Фоновая загрузка страниц с уменьшением до размера экрана и предзагрузкой соседних; индикатор загрузки и сообщение об ошибке для битой страницы.
- «Назад» на Android и Esc на ПК закрывают читалку; вне читалки «Назад» сворачивает приложение, как раньше.
- Выбранный режим (страницы / лента) запоминается между запусками.
- `library.Source.PageSizes`: размеры всех страниц галереи без полного декодирования.

## Non-goals

- Прогресс чтения (последняя страница, отметки «прочитано», прогресс на карточке).
- Pinch-zoom (в Fyne 2.8 нет жестов двумя пальцами), произвольные уровни масштаба.
- Порядок справа налево, двухстраничный разворот, автопрокрутка.
- Переход между галереями из читалки (следующая/предыдущая книга).

## Capabilities

### New Capabilities
- `reader`: открытие и закрытие читалки, постраничный режим, масштаб ×2 и перетаскивание, режим ленты, панель управления, загрузка страниц и ошибки, кнопка «Назад», сохранение режима.

### Modified Capabilities
- `library-scan`: новое требование — получение размеров страниц по заголовкам изображений.
- `library-view`: нажатие на карточку открывает читалку вместо toast.

## Impact

- Новый код: `internal/ui/reader/` (оболочка, постраничный вид, лента, панель, жесты), `internal/pages/` (загрузка, уменьшение, резка, кэш страниц — без виджетов).
- Изменения: `internal/library/source.go` (`PageSizes`), `internal/ui/shell.go` (слой читалки, обработка «Назад»/Esc), `internal/ui/screens/library.go` (открытие читалки).
- Хранение: одна настройка режима в `fyne.App.Preferences()`; другого хранилища нет.
- Зависимости не добавляются.
