## ADDED Requirements

### Requirement: Поля и направление сортировки
Система SHALL позволять сортировать галереи по полям: название, число страниц, размер файла, дата добавления (время изменения файла), дата выпуска (`Uploaded`: из `meta.json`, а если её нет, то из `ComicInfo.xml`). Для каждого поля MUST быть доступны оба направления. Пустое значение (нет даты, нет страниц) MUST считаться наименьшим: при возрастании такие записи идут в начале, при убывании в конце. Равные значения MUST упорядочиваться по ключу галереи в натуральном порядке. Локальная сортировка MUST давать тот же порядок, что и запрос к индексу с той же сортировкой.

#### Scenario: Размер по убыванию
- **WHEN** выбрано поле «Размер» с убыванием
- **THEN** самый большой файл стоит первым

#### Scenario: Пустая дата выпуска при убывании
- **WHEN** выбрана «Дата выпуска» с убыванием, а у одной галереи нет ни `meta.json`, ни `ComicInfo.xml` с датой
- **THEN** эта галерея стоит последней

#### Scenario: Пустая дата выпуска при возрастании
- **WHEN** выбрана «Дата выпуска» с возрастанием
- **THEN** галерея без даты стоит первой

#### Scenario: Равные значения
- **WHEN** у двух галерей одинаковое число страниц
- **THEN** они идут в натуральном порядке ключей (`a2` раньше `a10`)

#### Scenario: Совпадение с индексом
- **WHEN** один и тот же набор галерей сортируется функцией сортировки и запросом к индексу по каждому полю в обе стороны
- **THEN** порядок одинаков

### Requirement: Контрол сортировки
Над сеткой на вкладках «Библиотека» и «Поиск» SHALL отображаться контрол с названием текущего поля и стрелкой направления. Нажатие MUST открывать меню с пятью полями и пунктом «По умолчанию». Выбор другого поля MUST ставить направление по умолчанию для этого поля: название по возрастанию, остальные по убыванию. Выбор текущего поля MUST инвертировать направление. После смены сортировки сетка MUST прокручиваться в начало. Если сортировка вкладки отличается от стартовой, контрол MUST быть подсвечен, а пункт «По умолчанию» MUST возвращать стартовую сортировку.

#### Scenario: Смена поля
- **WHEN** пользователь выбирает «Название»
- **THEN** галереи идут по названию по возрастанию, контрол показывает «Название ↑»

#### Scenario: Инверсия
- **WHEN** выбрано «Размер ↓» и пользователь снова выбирает «Размер»
- **THEN** направление становится «↑»

#### Scenario: Сброс
- **WHEN** на вкладке выбрана нестартовая сортировка и пользователь выбирает «По умолчанию»
- **THEN** действует стартовая сортировка, подсветка снимается

#### Scenario: Прокрутка
- **WHEN** сетка прокручена вниз и пользователь меняет сортировку
- **THEN** сетка показывает начало списка

### Requirement: Локальная сортировка без повторного запроса
Смена сортировки MUST упорядочивать уже загруженный список (весь скан в Библиотеке, последняя выдача в Поиске) и MUST NOT запускать сканирование или запрос к индексу.

#### Scenario: Смена сортировки в Поиске
- **WHEN** выполнен запрос `english` и пользователь меняет сортировку
- **THEN** запрос заново не выполняется, результаты переупорядочиваются

#### Scenario: Смена сортировки в Библиотеке
- **WHEN** пользователь меняет сортировку в Библиотеке
- **THEN** сканирование не запускается

### Requirement: Стартовая сортировка в настройках
В настройках SHALL быть стартовая сортировка (поле и направление), общая для Библиотеки и Поиска, по умолчанию «Дата добавления ↓». Она MUST сохраняться между запусками. Сортировка, выбранная на вкладке, MUST NOT сохраняться: при следующем запуске каждая вкладка использует стартовую. Изменение стартовой сортировки MUST применяться к вкладкам, где сортировку вручную не меняли.

#### Scenario: Новая установка
- **WHEN** приложение запущено впервые
- **THEN** обе вкладки показывают «Дата добавления ↓»

#### Scenario: Перезапуск
- **WHEN** на вкладке выбрано «Размер ↑», приложение перезапущено
- **THEN** вкладка использует стартовую сортировку из настроек

#### Scenario: Вкладки независимы
- **WHEN** в Библиотеке выбрано «Название», а на вкладке «Поиск» сортировка не менялась
- **THEN** «Поиск» остаётся на стартовой сортировке

#### Scenario: Смена стартовой сортировки
- **WHEN** в настройках стартовая сортировка меняется на «Страницы ↓», а на вкладке «Поиск» её вручную не меняли
- **THEN** «Поиск» сразу использует «Страницы ↓», а вручную изменённая вкладка остаётся как была

### Requirement: Локализация сортировки
Все подписи сортировки (название контрола, поля, направления, «По умолчанию», настройка) MUST быть в i18n на всех поддерживаемых языках.

#### Scenario: Русский интерфейс
- **WHEN** язык интерфейса русский
- **THEN** подписи сортировки на русском, поле даты называется «Дата выпуска»
