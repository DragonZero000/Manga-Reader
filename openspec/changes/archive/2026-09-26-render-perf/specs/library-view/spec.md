## MODIFIED Requirements

### Requirement: Загрузка миниатюр
Обложки MUST загружаться в фоне только для видимых карточек. Первая страница декодируется (JPEG, PNG, GIF, WebP) и уменьшается до размера области обложки карточки в физических пикселях экрана с сохранением пропорций. Большая сторона миниатюры MUST NOT превышать 512 пикселей, изображение MUST NOT увеличиваться. Миниатюра кэшируется в памяти по ключу галереи с учётом времени изменения архива. Объём кэша MUST быть ограничен в байтах; при переполнении вытесняются давно не показанные миниатюры.

Если карточка переиспользована для другой галереи до начала декодирования прежней обложки, прежний запрос MUST отменяться без декодирования. Из ожидающих запросов MUST сначала выполняться более новые. Декодирование и уменьшение MUST выполняться вне UI-потока; UI-поток MUST NOT масштабировать миниатюру.

Пока миниатюра загружается, карточка MUST показывать заглушку. Если обложку не удалось декодировать, карточка MUST показывать значок ошибки, а не пустое место.

#### Scenario: Быстрая прокрутка
- **WHEN** пользователь прокручивает сетку и карточка повторно становится видимой
- **THEN** обложка берётся из кэша без повторного декодирования

#### Scenario: Битое изображение
- **WHEN** первая страница архива не является корректным изображением
- **THEN** карточка показывает значок ошибки и название, остальные карточки не затронуты

#### Scenario: Переиспользование карточки
- **WHEN** виджет карточки переиспользуется для другой галереи, пока грузится прежняя обложка
- **THEN** в карточке появляется обложка новой галереи, а не прежней

#### Scenario: Отмена ушедших с экрана
- **WHEN** пользователь быстро пролистывает сетку из 200 карточек до конца
- **THEN** обложки карточек, которые ушли с экрана до начала их декодирования, не декодируются, а обложки видимых карточек загружаются в первую очередь

#### Scenario: Размер миниатюры
- **WHEN** область обложки карточки занимает 450×640 физических пикселей, а первая страница имеет размер 1400×2000
- **THEN** миниатюра имеет размер не больше 358×512 и не больше области обложки

#### Scenario: Лимит кэша
- **WHEN** в кэш добавляются миниатюры сверх лимита объёма
- **THEN** объём кэша не превышает лимит, вытесняются давно не показанные миниатюры
