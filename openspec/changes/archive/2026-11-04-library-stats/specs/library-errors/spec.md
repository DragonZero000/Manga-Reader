## MODIFIED Requirements

### Requirement: Вкладка «Ошибки»
Оболочка SHALL показывать вкладку «Ошибки» только если список ошибок не пуст; при пустом списке вкладки MUST NOT быть. Пока вкладка есть, её иконка и подпись MUST быть цвета ошибки темы (красные), независимо от того, просмотрены ли записи и выбрана ли вкладка. Вкладка содержит список записей: имя файла (путь относительно папки библиотеки), причина, время изменения. Непросмотренные записи MUST визуально выделяться (жирный шрифт и маркер). Порядок MUST быть: сначала более новые по времени изменения, при равенстве — по пути в натуральном порядке. Наличие вкладки MUST обновляться после каждого сканирования и удаления.

#### Scenario: Список ошибок
- **WHEN** в папке лежат ошибочные `a.jpg` (изменён вчера) и `b.mp4` (изменён сегодня)
- **THEN** вкладка «Ошибки» есть, красная, и показывает `b.mp4`, затем `a.jpg`, у каждой — причина и время

#### Scenario: Нет ошибок
- **WHEN** все файлы папки — корректные архивы
- **THEN** вкладки «Ошибки» нет

#### Scenario: Появление ошибки
- **WHEN** ошибок не было, и в папку скачан HTML вместо архива, библиотека пересканирована
- **THEN** появляется красная вкладка «Ошибки» с числом 1 на иконке

#### Scenario: Просмотренные ошибки
- **WHEN** пользователь открыл вкладку «Ошибки» и перешёл на другую, ошибки остались
- **THEN** вкладка остаётся красной, числа на иконке нет

### Requirement: Число непросмотренных ошибок на вкладке
Иконка вкладки «Ошибки» SHALL показывать число непросмотренных записей, если оно больше нуля; при числе больше 99 MUST показываться «99+». Если непросмотренных записей нет, число MUST NOT показываться. Число MUST обновляться после каждого сканирования и после открытия вкладки.

#### Scenario: Новые ошибки
- **WHEN** сканирование нашло 3 новых ошибочных файла, а вкладка «Ошибки» не открыта
- **THEN** на иконке вкладки показывается число 3

#### Scenario: Ошибки просмотрены
- **WHEN** пользователь открыл вкладку «Ошибки»
- **THEN** число на иконке исчезает

#### Scenario: Ошибка исчезла
- **WHEN** на иконке число 1, и пользователь удалил единственный ошибочный файл, библиотека пересканирована
- **THEN** вкладки «Ошибки» нет
