## MODIFIED Requirements

### Requirement: Единая модель произведения
Система SHALL представлять любое произведение, независимо от источника, единой моделью `Gallery` со следующими полями: ключ, внешний ID (необязательный), основное и альтернативное название, типизированные теги, дата загрузки на сайт, количество страниц, количество избранного на сайте, сканлейтор, упорядоченный список страниц, сведения о файле (путь, размер, время изменения), а также признак «в архиве есть `meta.json`». Признак MUST быть истинным, если сканер нашёл и разобрал `meta.json`, и ложным, если файла нет или он не разобрался.

#### Scenario: Модель без метаданных
- **WHEN** создаётся `Gallery` только с ключом и названием
- **THEN** необязательные поля имеют нулевые значения, список тегов пуст, признак `meta.json` ложен

#### Scenario: Архив с meta.json
- **WHEN** сканируется `testdata/example.zip` с корректным `meta.json`
- **THEN** у галереи признак `meta.json` истинен

#### Scenario: Повреждённый meta.json
- **WHEN** сканируется архив, где `meta.json` — не JSON
- **THEN** галерея создаётся по файлу, признак `meta.json` ложен
