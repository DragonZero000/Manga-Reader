## MODIFIED Requirements

### Requirement: Совпадение условий
Фильтры запроса SHALL проверяться так: тег («есть»/«нет») — точное совпадение нормализованного имени, а если тип указан — и типа; область тегов зависит от поля: `tag` и поля типов — действующие теги (оригинальные без скрытых плюс свои), `custom-tag` — только свои, `hidden-tag` — только скрытые оригинальные. `missing:<тип>` — нет ни одного действующего тега этого типа; `missing:tags` — нет ни одного действующего тега; `missing:meta` — признак `meta.json` у галереи ложен; с `-` — обратное. `title` — подстрока в основном или альтернативном названии; `scanlator` — подстрока (операция «содержит») или точное совпадение («равно»). Текстовые значения (имена тегов, `title`, `scanlator`) MUST сравниваться после той же нормализации, что и слова (NFKC, нижний регистр, `ё` → `е`). `pages` — по фактическому числу страниц; `favorites`, `id` — по значениям метаданных; `size` — по размеру файла; `uploaded` — по дате загрузки; `added` — по времени изменения файла. Произведение без значения поля (ноль, нулевая дата) MUST NOT удовлетворять числовым и датовым фильтрам по этому полю. Индекс в каталоге и индекс в памяти MUST давать одинаковые результаты для `missing`.

#### Scenario: Тег любого типа
- **WHEN** выполняется поиск `tag:japanese`
- **THEN** находится `example.zip` (тег `language:japanese`)

#### Scenario: Тег точного типа
- **WHEN** выполняется поиск `artist:japanese`
- **THEN** `example.zip` не находится

#### Scenario: Подстрока не совпадает с тегом
- **WHEN** выполняется поиск `tag:japan`
- **THEN** `example.zip` не находится: для тега нужно точное имя

#### Scenario: Исключение
- **WHEN** выполняется поиск `english -tag:"tag 3"`
- **THEN** `example.zip` не находится

#### Scenario: Число страниц
- **WHEN** выполняются поиски `pages:2` и `pages:>2`
- **THEN** `example.zip` находится первым поиском и не находится вторым

#### Scenario: Нет значения
- **WHEN** архив без `meta.json` и выполняется поиск `favorites:<10`
- **THEN** этот архив не находится

#### Scenario: Тег с ё
- **WHEN** у произведения тег `tag:ёжик`, и выполняется поиск `tag:ежик`
- **THEN** произведение находится

#### Scenario: Скрытый тег
- **WHEN** у `example.zip` скрыт `tag:tag 3`
- **THEN** поиск `tag:"tag 3"` не находит `example.zip`, `-tag:"tag 3"` и `hidden-tag:"tag 3"` находят его

#### Scenario: Свой тег
- **WHEN** у `example.zip` есть свой тег `character:alice`
- **THEN** его находят `character:alice`, `tag:alice` и `custom-tag:alice`; `custom-tag:"tag 1"` его не находит

#### Scenario: Нет meta.json
- **WHEN** в библиотеке `example.zip` (с `meta.json`) и `bare.zip` (без него, без своих тегов)
- **THEN** `missing:meta` и `missing:tags` находят только `bare.zip`, `-missing:meta` — только `example.zip`

#### Scenario: Нет автора с учётом своих и скрытых
- **WHEN** у `bare.zip` есть свой тег `artist:alice`, а у `example.zip` скрыт единственный тег `artist`
- **THEN** `missing:artist` находит `example.zip` и не находит `bare.zip`
