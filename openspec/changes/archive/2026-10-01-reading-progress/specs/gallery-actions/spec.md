## MODIFIED Requirements

### Requirement: Состав меню карточки
Меню карточки SHALL содержать пункты в порядке: «Открыть» (страница произведения), «Читать» (читалка с первой страницы), «Открыть в браузере», «Скопировать название», «Показать в папке», «Сбросить прогресс», разделитель, «Удалить…». «Открыть в браузере» MUST показываться только при наличии ссылки у произведения и MUST работать так же, как одноимённая кнопка страницы произведения (см. `gallery-details`). «Показать в папке» MUST показываться только на Windows. «Сбросить прогресс» MUST показываться только при наличии сохранённого прогресса (в том числе отметки «дочитано»), см. `reading-progress`.

#### Scenario: Меню со ссылкой на Windows
- **WHEN** на Windows открыто меню галереи со ссылкой без прогресса
- **THEN** меню содержит «Открыть», «Читать», «Открыть в браузере», «Скопировать название», «Показать в папке», «Удалить…»

#### Scenario: Меню без ссылки на Android
- **WHEN** на Android открыто меню галереи без ссылки и без прогресса
- **THEN** меню содержит «Открыть», «Читать», «Скопировать название», «Удалить…»

#### Scenario: Меню с прогрессом
- **WHEN** открыто меню галереи, у которой сохранён прогресс
- **THEN** перед разделителем есть пункт «Сбросить прогресс»

#### Scenario: Читать из меню
- **WHEN** пользователь выбирает «Читать»
- **THEN** открывается читалка на странице 1; после её закрытия пользователь возвращается к сетке

### Requirement: Меню страницы произведения
Верхняя полоса страницы произведения SHALL содержать кнопку «⋮» справа. Её меню MUST содержать только действия, которых нет на самой странице: «Скопировать название», «Показать в папке» (только Windows), «Сбросить прогресс» (только при наличии прогресса), разделитель, «Удалить…». После удаления со страницы произведения страница MUST закрываться, и пользователь MUST возвращаться к сетке. После сброса прогресса кнопка «Продолжить» на странице MUST исчезать.

#### Scenario: Меню страницы
- **WHEN** на Windows пользователь нажимает «⋮» на странице произведения без прогресса
- **THEN** меню содержит «Скопировать название», «Показать в папке», «Удалить…» и не содержит «Читать», «Открыть в браузере» и «Сбросить прогресс»

#### Scenario: Сброс со страницы
- **WHEN** на странице произведения с кнопкой «Продолжить · стр. 34» пользователь выбирает «Сбросить прогресс»
- **THEN** кнопка «Продолжить» исчезает, показывается toast «Прогресс сброшен»

#### Scenario: Удаление со страницы
- **WHEN** пользователь удаляет произведение из меню страницы и подтверждает
- **THEN** страница закрывается, карточки удалённого произведения в сетке нет
