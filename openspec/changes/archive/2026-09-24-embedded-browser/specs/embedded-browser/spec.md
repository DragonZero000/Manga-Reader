## ADDED Requirements

### Requirement: Портативный браузер в папке приложения
На Windows приложение SHALL использовать Firefox ESR из папки `browser\firefox\` рядом с `mangareader.exe` и профиль из папки `browser\profile\`. Приложение MUST NOT использовать установленные в системе браузеры и их профили; данные браузера (профиль, кэш, загрузки, настройки) MUST храниться только в папке приложения. Служебные значения, которые Firefox сам записывает в `HKCU\Software\Mozilla\Firefox` с путём встроенного браузера, MUST удаляться после закрытия браузера и при запуске приложения (если браузер в прошлый раз не закрылся штатно); значения других установок Firefox MUST NOT затрагиваться. Браузер MUST настраиваться без корпоративных политик Firefox (`policies.json`), чтобы Firefox не показывал «Ваш браузер управляется Вашей организацией». Если `browser\firefox\firefox.exe` отсутствует, открытие браузера MUST показывать ошибку с ожидаемым путём.

#### Scenario: Первый запуск браузера
- **WHEN** пользователь впервые нажимает «Браузер», а папки `browser\profile\` нет
- **THEN** профиль создаётся в `browser\profile\`, открывается окно браузера без приветственных страниц Firefox

#### Scenario: Установленный Firefox не затрагивается
- **WHEN** в системе установлен и запущен обычный Firefox
- **THEN** встроенный браузер открывается отдельно со своим профилем, открытые окна системного Firefox и его профиль не меняются

#### Scenario: Следы в реестре убираются
- **WHEN** пользователь открыл и закрыл встроенный браузер
- **THEN** в `HKCU\Software\Mozilla\Firefox` нет значений и ключей с путём встроенного браузера, значения установленного Firefox на месте

#### Scenario: Браузер не найден
- **WHEN** папки `browser\firefox\` нет (например, запуск через `go run`)
- **THEN** показывается ошибка «Браузер не найден: <путь к firefox.exe>», приложение продолжает работу

#### Scenario: Нет пометки об организации
- **WHEN** пользователь открывает настройки Firefox во встроенном браузере
- **THEN** надписи «Ваш браузер управляется Вашей организацией» нет

### Requirement: Окно браузера в стиле Telegram
Браузер SHALL открываться отдельным окном, привязанным к главному окну приложения: окно браузера MUST оставаться поверх главного окна, сворачиваться и восстанавливаться вместе с ним и MUST NOT иметь отдельной кнопки на панели задач. Шапка браузера MUST содержать только кнопки «Назад», «Вперёд», «Обновить», адресную строку (с поиском), «Все вкладки» (список открытых вкладок с переключением и закрытием), «Новая вкладка», кнопку закладок, кнопку загрузок, кнопку расширений и кнопку «MangaReader»; полоса вкладок MUST NOT показываться. Ссылки, открывающие новую вкладку, MUST открываться в новой вкладке того же окна; всплывающие окна сайтов MUST привязываться к главному окну так же, как основное. Повторное нажатие «Браузер» при открытом браузере MUST выводить его окно на передний план, а не запускать второй экземпляр. Закрытие главного окна MUST закрывать браузер.

#### Scenario: Открытие
- **WHEN** пользователь нажимает «Браузер» на панели библиотеки
- **THEN** открывается окно браузера поверх главного окна с домашней страницей и минимальной шапкой без полосы вкладок

#### Scenario: Ссылка в новой вкладке
- **WHEN** на странице нажата ссылка с `target="_blank"`
- **THEN** страница открывается в новой вкладке того же окна; через «Все вкладки» можно вернуться на прежнюю

#### Scenario: Переключение вкладок
- **WHEN** открыто 3 вкладки и пользователь нажимает «Все вкладки»
- **THEN** показывается список из 3 вкладок с заголовками; выбор вкладки переключает на неё

#### Scenario: Кнопка «MangaReader»
- **WHEN** пользователь нажимает «MangaReader» в шапке браузера
- **THEN** окно браузера сворачивается, окно приложения выходит на передний план; кнопка «Браузер» в приложении возвращает окно браузера

#### Scenario: Повторное открытие
- **WHEN** браузер открыт, и пользователь снова нажимает «Браузер»
- **THEN** окно браузера выходит на передний план, второй процесс Firefox не запускается

#### Scenario: Сворачивание
- **WHEN** пользователь сворачивает главное окно
- **THEN** окно браузера сворачивается вместе с ним

#### Scenario: Выход из приложения
- **WHEN** пользователь закрывает главное окно при открытом браузере
- **THEN** браузер закрывается, процесс Firefox завершается

### Requirement: Загрузки в папку библиотеки
Все файлы, скачанные встроенным браузером, SHALL сохраняться в корень папки библиотеки без диалога выбора места. Браузер MUST NOT автоматически открывать скачанные файлы. Проверка файла после загрузки MUST выполняться механизмами наблюдения за папкой и списка ошибок; невалидный файл MUST оставаться в папке.

#### Scenario: Скачивание архива
- **WHEN** пользователь нажимает ссылку на скачивание `g-1.zip`
- **THEN** файл сохраняется в `manga\g-1.zip` без вопросов и появляется в библиотеке

#### Scenario: Скачался невалидный файл
- **WHEN** сайт вместо архива отдал HTML-страницу, сохранённую как `g-2.zip`
- **THEN** файл остаётся в `manga\`, а приложение показывает ошибку о невалидном файле

### Requirement: Настройки браузера
На Windows экран «Настройки» SHALL содержать раздел «Браузер» с полем «Домашняя страница» (URL; пусто — стартовая страница Firefox), кнопками «Поисковик» (открывает настройки поиска Firefox, где выбирается поисковик по умолчанию; выбор сохраняется в профиле), «Расширения» (открывает управление расширениями в браузере) и кнопками очистки данных. Домашняя страница MUST сохраняться в настройках приложения и MUST применяться при следующем запуске браузера; если браузер открыт, MUST показываться подсказка «Изменения вступят в силу после перезапуска браузера». Тема браузера MUST быть всегда тёмной, независимо от темы Windows. Обновления Firefox, телеметрия, исследования, спонсорский контент и приветственные страницы MUST быть отключены. На Android раздел «Браузер» MUST NOT показываться.

#### Scenario: Смена домашней страницы
- **WHEN** пользователь задаёт домашнюю страницу `https://example.org` и открывает браузер
- **THEN** браузер открывается на `https://example.org`

#### Scenario: Смена поисковика
- **WHEN** пользователь нажимает «Поисковик», выбирает в настройках Firefox DuckDuckGo и после перезапуска браузера вводит в адресной строке слова
- **THEN** выполняется поиск в DuckDuckGo

#### Scenario: Расширения
- **WHEN** пользователь нажимает «Расширения»
- **THEN** в браузере открывается страница управления расширениями; расширение, установленное с addons.mozilla.org, остаётся после перезапуска браузера и приложения

#### Scenario: Тёмная тема
- **WHEN** в Windows включена светлая тема
- **THEN** шапка браузера тёмная, сайты получают `prefers-color-scheme: dark`

### Requirement: Закладки
Браузер SHALL поддерживать закладки Firefox: добавление звёздочкой в адресной строке и доступ через кнопку закладок в шапке. Закладки MUST храниться в профиле `browser\profile\` и сохраняться между запусками.

#### Scenario: Добавление закладки
- **WHEN** пользователь добавляет закладку и перезапускает приложение
- **THEN** закладка доступна в меню закладок браузера

### Requirement: Очистка данных браузера
Раздел «Браузер» SHALL содержать кнопки «Очистить cookies и данные сайтов» и «Очистить историю». Каждая MUST спрашивать подтверждение. Очистка MUST выполняться средствами Firefox при следующем открытии браузера, до загрузки любой страницы; если браузер открыт, MUST предлагаться закрыть его. Очистка cookies MUST удалять cookies, хранилища сайтов и кэш, не затрагивая историю, закладки и расширения. Очистка истории MUST удалять историю посещений, историю загрузок и данные форм, не затрагивая закладки, расширения и cookies. Каждая очистка MUST выполняться один раз. После подтверждения MUST показываться toast «Будет очищено при следующем открытии браузера».

#### Scenario: Очистка cookies
- **WHEN** пользователь очищает cookies и данные сайтов и открывает браузер
- **THEN** на сайтах нет входа в аккаунты, закладки и история на месте

#### Scenario: Однократность
- **WHEN** после очистки cookies пользователь снова вошёл на сайт, закрыл и открыл браузер
- **THEN** вход на сайт сохранился

#### Scenario: Очистка истории
- **WHEN** пользователь очищает историю и открывает браузер
- **THEN** история посещений пуста, закладки на месте

#### Scenario: Браузер открыт
- **WHEN** пользователь нажимает «Очистить историю» при открытом браузере
- **THEN** приложение предлагает закрыть браузер; после согласия браузер закрывается, а при следующем открытии история пуста

### Requirement: Источник загрузки
Когда встроенный браузер скачивает файл в папку библиотеки, приложение SHALL запоминать адрес страницы, открытой в активной вкладке в момент начала загрузки, — независимо от политики Referer сайта и от перенаправлений адреса файла. Адрес MUST сохраняться вместе с файлом (в NTFS-потоке файла `:mangareader.source`), чтобы переживать переименование и перемещение файла на том же диске. Использоваться MUST только абсолютный адрес `http` или `https`. Для файлов без сохранённого адреса MUST использоваться `ReferrerUrl` из метки загрузки Windows (`Zone.Identifier`), если он есть. Сохранённый адрес MUST становиться ссылкой галереи без ручного обновления библиотеки.

#### Scenario: Сайт обрезает Referer
- **WHEN** на странице `https://site.example/g/535147/` пользователь нажал «Скачать», файл отдаётся через `https://api.site.example/download?id=535147` с перенаправлением на `https://cdn.site.example/f/abc.zip`, а сайт передаёт в Referer только `https://site.example/`
- **THEN** ссылка галереи — `https://site.example/g/535147/`

#### Scenario: Файл переименован
- **WHEN** пользователь переименовал скачанный `g-535147.zip` в `мой.zip` на том же диске
- **THEN** ссылка галереи `мой.zip` — по-прежнему `https://site.example/g/535147/`

#### Scenario: Скачан другим браузером
- **WHEN** архив скачан системным браузером, записавшим в метку загрузки `ReferrerUrl=https://b.example/x`
- **THEN** ссылка галереи — `https://b.example/x`

#### Scenario: Адреса нет
- **WHEN** архив скопирован с флешки FAT32
- **THEN** ссылки нет
