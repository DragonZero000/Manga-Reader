## MODIFIED Requirements

### Requirement: Сообщения об ошибках
Ошибка разбора SHALL содержать проблемный фрагмент запроса и понятную причину на языке интерфейса (см. `localization`). Незакрытая кавычка MUST считаться закрытой в конце строки (без ошибки). Пустое значение (`pages:`) MUST приводить к ошибке.

#### Scenario: Незакрытая кавычка
- **WHEN** разбирается `tag:"tag 1`
- **THEN** получается фильтр «есть тег `tag 1`» без ошибки

#### Scenario: Пустое значение
- **WHEN** разбирается `pages:` при русском интерфейсе
- **THEN** возвращается ошибка «pages: не указано значение»

#### Scenario: Пустое значение по-английски
- **WHEN** разбирается `pages:` при английском интерфейсе
- **THEN** возвращается ошибка «pages: no value specified»
