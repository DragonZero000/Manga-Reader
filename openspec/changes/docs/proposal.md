## Why

Репозиторий опубликован, первый релиз `v0.1.0` вышел, но вся документация — один README на русском на 215 строк. В нём смешаны инструкции для пользователя, сборка и устройство кода, есть устаревшие разделы (переход со старых версий, которых публично не было) и потерянный заголовок. Англоязычный посетитель GitHub не поймёт, что это за проект. Читалка, поиск и страница произведения не описаны вовсе. Нужна документация, по которой человек может понять, что это и как этим пользоваться, скачать релиз или доработать приложение, — на английском и русском.

## What Changes

- `README.md` (English) и `README.ru.md` (русский) — витрина: что это, возможности, скриншоты, скачать и установить, системные требования, быстрый старт для разработчика, ссылки на документацию, лицензия. Явная пометка, что интерфейс пока только на русском. Вверху каждого файла — переключатель языка.
- `docs/en/` и `docs/ru/` с одинаковыми именами файлов:
  - `user-guide.md` — библиотека и папка (ПК/Android), формат архива и `meta.json`, чтение, поиск и его синтаксис, страница произведения, встроенный браузер (Windows/Android), ошибки библиотеки, настройки;
  - `building.md` — требования, команды `make`, сборка Android, версия, выпуск релиза, ключ подписи и секреты GitHub (подробная пошаговая инструкция);
  - `architecture.md` — пакеты и их границы, платформенные build-теги, потоки UI (`fyne.Do`), встроенный браузер, инструменты сборки, CI и OpenSpec.
- `CONTRIBUTING.md` и `CONTRIBUTING.ru.md`: как предложить изменение, проверки, процесс OpenSpec, правило двух языков в документации, строки интерфейса, обновление `THIRD_PARTY_NOTICES.md`.
- `docs/images/` — скриншоты, общие для обоих языков.
- Проверка в `go test` (а значит, в `make test` и CI):
  - у каждого документа есть пара на другом языке;
  - в каждом документе есть переключатель языка;
  - все относительные ссылки в Markdown ведут на существующие файлы.
- Удаляются устаревшие разделы: переход с версий до Gradle и со старых папок библиотеки (публичных релизов до `0.1.0` не было).

## Non-goals

- Перевод интерфейса приложения (будущее изменение `i18n`).
- Сайт документации (GitHub Pages, mkdocs) — достаточно Markdown в репозитории.
- Перевод `THIRD_PARTY_NOTICES.md`: юридический документ остаётся одним, на английском; русские документы ссылаются на него.
- Linux (`linux-support`): в документации указано, что Linux пока не поддерживается.
- Описание (About) и темы репозитория на GitHub — автор задаёт их в настройках; в tasks есть подсказка с текстом.
