# gallery-actions Specification

## Purpose

Меню действий с произведением: кнопка «⋮» на карточке (и правый клик / долгое нажатие), меню страницы произведения, копирование названия, «Показать в папке», удаление с подтверждением (корзина на Windows, безвозвратно на Android) и запрет удаления открытого произведения.
## Requirements
### Requirement: Кнопка «⋮» на карточке
Каждая карточка в сетке библиотеки и поиска SHALL показывать в правом верхнем углу обложки кнопку «⋮» на полупрозрачном круглом фоне, через который видна обложка. Область нажатия кнопки на телефоне MUST быть не меньше 40 dp даже при 4 карточках в ряду. Нажатие на «⋮» MUST открывать меню действий и MUST NOT открывать страницу произведения. Правый клик по карточке (ПК) и долгое нажатие (телефон) MUST открывать то же меню.

#### Scenario: Открытие меню
- **WHEN** пользователь нажимает «⋮» на карточке `example.zip`
- **THEN** рядом с кнопкой открывается меню действий, страница произведения не открывается

#### Scenario: Обложка видна
- **WHEN** карточка показывает светлую обложку
- **THEN** под кнопкой «⋮» видна часть обложки, значок «⋮» различим

#### Scenario: Долгое нажатие
- **WHEN** на телефоне пользователь удерживает палец на карточке
- **THEN** открывается то же меню действий

#### Scenario: Обычное нажатие
- **WHEN** пользователь нажимает на карточку вне кнопки «⋮»
- **THEN** открывается страница произведения, как раньше

### Requirement: Состав меню карточки
Меню карточки SHALL содержать пункты в порядке: «Открыть» (страница произведения), «Читать» (читалка с первой страницы), «Открыть в браузере», «Скопировать название», «Показать в папке», «Сбросить прогресс», разделитель, «Удалить…». «Открыть в браузере» MUST показываться только при наличии ссылки у произведения и MUST работать так же, как одноимённая кнопка страницы произведения (см. `gallery-details`). «Показать в папке» MUST показываться только на Windows. «Сбросить прогресс» MUST показываться только при наличии сохранённого прогресса (в том числе отметки «дочитано»), см. `reading-progress`.

#### Scenario: Меню со ссылкой на Windows
- **WHEN** на Windows открыто меню галереи со ссылкой без прогресса
- **THEN** меню содержит «Открыть», «Читать», «Открыть в браузере», «Скопировать название», «Показать в папке», «Удалить…»

#### Scenario: Меню без ссылки на Android
- **WHEN** на Android открыто меню галереи без ссылки и без прогресса
- **THEN** меню содержит «Открыть», «Читать», «Скопировать название», «Удалить…»

#### Scenario: Меню с прогрессом
- **WHEN** открыто меню галереи, у которой сохранён прогресс
- **THEN** перед разделителем есть пункт «Сбросить прогресс»

#### Scenario: Читать из меню
- **WHEN** пользователь выбирает «Читать»
- **THEN** открывается читалка на странице 1; после её закрытия пользователь возвращается к сетке

### Requirement: Меню страницы произведения
Верхняя полоса страницы произведения SHALL содержать кнопку «⋮» справа. Её меню MUST содержать только действия, которых нет на самой странице: «Скопировать название», «Показать в папке» (только Windows), «Сбросить прогресс» (только при наличии прогресса), разделитель, «Удалить…». После удаления со страницы произведения страница MUST закрываться, и пользователь MUST возвращаться к сетке. После сброса прогресса кнопка «Продолжить» на странице MUST исчезать.

#### Scenario: Меню страницы
- **WHEN** на Windows пользователь нажимает «⋮» на странице произведения без прогресса
- **THEN** меню содержит «Скопировать название», «Показать в папке», «Удалить…» и не содержит «Читать», «Открыть в браузере» и «Сбросить прогресс»

#### Scenario: Сброс со страницы
- **WHEN** на странице произведения с кнопкой «Продолжить · стр. 34» пользователь выбирает «Сбросить прогресс»
- **THEN** кнопка «Продолжить» исчезает, показывается toast «Прогресс сброшен»

#### Scenario: Удаление со страницы
- **WHEN** пользователь удаляет произведение из меню страницы и подтверждает
- **THEN** страница закрывается, карточки удалённого произведения в сетке нет

### Requirement: Скопировать название
Пункт «Скопировать название» SHALL помещать в буфер обмена основное название произведения и показывать toast «Название скопировано».

#### Scenario: Копирование
- **WHEN** пользователь выбирает «Скопировать название» у `example.zip`
- **THEN** буфер обмена содержит «english name», показывается toast «Название скопировано»

### Requirement: Показать в папке
На Windows пункт «Показать в папке» SHALL открывать Проводник с папкой, содержащей архив, и выделять в нём файл архива. Если файла нет, MUST показываться toast с ошибкой.

#### Scenario: Показ файла
- **WHEN** пользователь выбирает «Показать в папке» у `series/vol1.zip`
- **THEN** открывается Проводник в папке `series` библиотеки, `vol1.zip` выделен

### Requirement: Удаление с подтверждением
Пункт «Удалить…» SHALL показывать диалог подтверждения с названием произведения и путём файла относительно папки библиотеки. Текст и кнопка MUST отражать способ удаления:
- Windows, корзина доступна: «Переместить в корзину?», кнопка «В корзину».
- Windows, корзины на диске нет: «Корзина недоступна. Удалить безвозвратно?», кнопка «Удалить».
- Android: «Файл будет удалён безвозвратно», кнопка «Удалить».

Отмена MUST ничего не менять. Удаление MUST выполняться в фоне; результат MUST применяться в UI-потоке. После успешного удаления карточка MUST сразу исчезать из сетки библиотеки и из текущего результата поиска, счётчики MUST обновляться, а библиотека MUST пересканироваться (каталог, индекс поиска и ссылки обновляются как при удалении файла вручную). Если файл занят другой программой или удаление не удалось, MUST показываться toast с причиной, карточка MUST оставаться.

#### Scenario: Удаление в корзину
- **WHEN** на Windows пользователь выбирает «Удалить…» у `example.zip` и нажимает «В корзину»
- **THEN** `example.zip` лежит в корзине Windows, карточки нет в библиотеке и в результатах поиска

#### Scenario: Нет корзины
- **WHEN** на Windows папка библиотеки на флешке без корзины, пользователь выбирает «Удалить…»
- **THEN** диалог сообщает «Корзина недоступна. Удалить безвозвратно?»; после подтверждения файл удалён

#### Scenario: Удаление на Android
- **WHEN** на Android пользователь выбирает «Удалить…» и подтверждает
- **THEN** файл удалён из выбранной папки, карточки нет

#### Scenario: Отмена
- **WHEN** пользователь нажимает «Отмена» в диалоге удаления
- **THEN** файл и карточка на месте

#### Scenario: Файл занят
- **WHEN** архив открыт другой программой, которая запрещает удаление
- **THEN** показывается toast «Файл занят другой программой», карточка на месте

#### Scenario: Доступ только на чтение (Android)
- **WHEN** на Android доступ к папке выдан только на чтение, и пользователь выбирает «Удалить…»
- **THEN** приложение объясняет, что нужен доступ на запись, и открывает системный выбор папки; файл не удаляется

### Requirement: Открытое произведение не удаляется
Перед удалением приложение SHALL проверять, не открыто ли произведение в читалке. Если открыто, удаление MUST отклоняться с сообщением «Произведение открыто в читалке — закройте его и повторите», файл MUST NOT меняться. Страница произведения, с которой запущено удаление, открытым произведением не считается.

#### Scenario: Открыто в читалке
- **WHEN** удаление запрошено для галереи, открытой сейчас в читалке
- **THEN** показывается сообщение, файл на месте
