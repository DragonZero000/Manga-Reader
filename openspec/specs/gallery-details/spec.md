# gallery-details Specification

## Purpose

Страница произведения между библиотекой и читалкой: обложка, названия, кнопка «Читать», теги по типам и сведения о произведении; пустые поля не показываются.
## Requirements
### Requirement: Открытие и закрытие страницы произведения
Страница произведения SHALL открываться поверх вкладок на весь экран при нажатии на карточку в библиотеке и показываться с начала (прокрутка в самом верху). Верхняя полоса MUST содержать кнопку «Назад». Кнопка «Назад» на полосе, кнопка «Назад» на Android и клавиша Esc на ПК MUST закрывать страницу произведения и возвращать библиотеку в прежнем состоянии.

#### Scenario: Открытие
- **WHEN** пользователь нажимает на карточку `example.zip`
- **THEN** открывается страница произведения «english name», вкладки не видны, содержимое прокручено в начало

#### Scenario: Закрытие кнопкой
- **WHEN** пользователь нажимает «Назад» на верхней полосе
- **THEN** страница произведения скрывается, библиотека показана с тем же положением прокрутки

#### Scenario: Esc
- **WHEN** страница произведения открыта, читалка закрыта, и пользователь нажимает Esc
- **THEN** страница произведения закрывается

### Requirement: Обложка
Первым элементом страницы SHALL быть первая страница произведения, вписанная в ширину области содержимого с сохранением пропорций, но не выше 60% высоты экрана. Пока загружается изображение в полном размере, MUST показываться миниатюра из кэша обложек библиотеки (если она есть) или индикатор загрузки. Если обложку не удалось прочитать, MUST показываться значок ошибки, а остальные сведения — отображаться. Нажатие на обложку MUST открывать читалку с первой страницы.

#### Scenario: Показ обложки
- **WHEN** открывается страница `example.zip`
- **THEN** вверху показывается изображение `example/1.jpg` целиком, без искажения пропорций

#### Scenario: Высокая обложка
- **WHEN** первая страница имеет размер 800×20000
- **THEN** обложка отображается целиком по высоте не более 60% экрана, по центру

#### Scenario: Битая обложка
- **WHEN** первая страница архива не является изображением
- **THEN** на месте обложки показывается значок ошибки, название, теги и сведения показываются

#### Scenario: Нажатие на обложку
- **WHEN** пользователь нажимает на обложку
- **THEN** открывается читалка на странице 1

### Requirement: Название и кнопка «Читать»
Под обложкой SHALL показываться основное название (с переносом по словам, без обрезки) и, если оно есть, альтернативное название менее заметным стилем. Под названиями MUST располагаться кнопка «Читать», открывающая читалку с первой страницы.

#### Scenario: Оба названия
- **WHEN** открывается страница `example.zip`
- **THEN** показываются «english name» и под ним «japanease name», затем кнопка «Читать»

#### Scenario: Только основное название
- **WHEN** у произведения нет альтернативного названия
- **THEN** строка альтернативного названия не показывается и не оставляет пустого места

### Requirement: Теги по типам
Теги SHALL показываться группами по типам в фиксированном порядке: «Автор» (`artist`), «Группа» (`group`), «Пародия» (`parody`), «Персонаж» (`character`), «Язык» (`language`), «Категория» (`category`), «Теги» (`tag`), затем группы неизвестных типов в алфавитном порядке с названием типа. Внутри группы теги MUST идти в порядке из `meta.json` и переноситься по строкам по ширине экрана. Группы без тегов MUST NOT показываться; если тегов нет совсем, раздел тегов MUST NOT показываться. Нажатие на тег MUST открывать поиск по этому тегу: для известного типа — `тип:"имя"`, для неизвестного — `tag:"имя"`.

#### Scenario: Группировка
- **WHEN** открывается страница `example.zip`
- **THEN** показываются группы «Автор: artist 1», «Пародия: parody 1», «Персонаж: character 1», «Язык: japanese», «Категория: doujinshi», «Теги: tag 1, tag 2, tag 3» в этом порядке

#### Scenario: Неизвестный тип
- **WHEN** у произведения есть тег типа `circle`
- **THEN** он показывается в отдельной группе «circle» после известных групп

#### Scenario: Нет тегов
- **WHEN** архив без `meta.json`
- **THEN** раздел тегов не показывается

#### Scenario: Нажатие на тег
- **WHEN** пользователь нажимает на тег «artist 1» в группе «Автор»
- **THEN** открывается вкладка «Поиск» с запросом `artist:"artist 1"` и результатами

### Requirement: Сведения о произведении
После тегов SHALL показываться сведения в виде пар «название — значение»: «Страниц» (фактическое число; если в метаданных указано другое — в скобках «в метаданных: N»), «ID», «Загружено» (дата загрузки на сайт, формат ДД.ММ.ГГГГ), «Избранное» (с разделением разрядов), «Сканлейтор», «Файл» (путь относительно папки библиотеки), «Размер» (в КБ/МБ/ГБ с одним знаком после запятой), «Изменён» (дата и время изменения файла, ДД.ММ.ГГГГ ЧЧ:ММ). Любое поле с пустым значением (пустая строка или строка из одних пробелов, ноль, нулевая дата) MUST NOT показываться — ни подпись, ни значение; исключений нет. Если не осталось ни одного поля, раздел сведений MUST NOT показываться.

#### Scenario: Эталонный архив
- **WHEN** открывается страница `example.zip`
- **THEN** показываются «Страниц: 2», «ID: 535147», «Загружено: 15.10.2024», «Избранное: 806», «Файл: example.zip», размер «31,0 КБ» и дата изменения файла; строка «Сканлейтор» не показывается

#### Scenario: Расхождение числа страниц
- **WHEN** в архиве 3 изображения, а `num_pages` в `meta.json` равно 5
- **THEN** показывается «Страниц: 3 (в метаданных: 5)»

#### Scenario: Архив без метаданных
- **WHEN** архив без `meta.json`
- **THEN** строки «ID», «Загружено», «Избранное» и «Сканлейтор» не показываются; показываются только поля с непустыми значениями («Страниц», «Файл», «Размер», «Изменён»)

#### Scenario: Пустое значение файлового поля
- **WHEN** размер файла равен 0 или время изменения файла неизвестно
- **THEN** строка «Размер» или «Изменён» соответственно не показывается

#### Scenario: Сканлейтор из пробелов
- **WHEN** в `meta.json` поле `scanlator` равно `"  "`
- **THEN** строка «Сканлейтор» не показывается

### Requirement: Кнопка «Открыть в браузере»
Если у произведения есть ссылка, рядом с кнопкой «Читать» SHALL показываться кнопка «Открыть в браузере». Она MUST открывать ссылку во встроенном браузере: на Windows — запуская его или выводя на передний план открытое окно; на Android — в новой вкладке встроенного браузера, открывая его экран поверх читалки. Если ссылки нет, кнопка MUST NOT показываться и MUST NOT оставлять пустого места.

#### Scenario: Ссылка есть (Windows)
- **WHEN** на Windows открыта страница произведения со ссылкой `https://site.example/g/535147/`, и пользователь нажимает «Открыть в браузере»
- **THEN** встроенный браузер показывает `https://site.example/g/535147/`

#### Scenario: Ссылка есть (Android)
- **WHEN** на Android пользователь нажимает «Открыть в браузере» на странице со ссылкой `https://site.example/g/535147/`
- **THEN** открывается экран встроенного браузера с новой вкладкой `https://site.example/g/535147/`, прежние вкладки сохраняются

#### Scenario: Ссылки нет
- **WHEN** открыта страница `example.zip` без ссылки
- **THEN** кнопка «Открыть в браузере» не показывается
