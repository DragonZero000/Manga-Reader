# library-view Specification

## Purpose

Экран «Библиотека»: сетка галерей с обложками, фоновая загрузка миниатюр, ручное и автоматическое обновление, пустое состояние и отображение ошибок.
## Requirements
### Requirement: Сетка библиотеки
Экран «Библиотека» SHALL показывать найденные галереи сеткой карточек. Каждая карточка MUST содержать обложку и основное название (не более двух строк, длинное название обрезается). Сетка MUST создавать карточки только для видимых элементов, чтобы библиотека из сотен архивов не замедляла интерфейс.

#### Scenario: Отображение архива
- **WHEN** в папке библиотеки лежит `example.zip` и сканирование завершено
- **THEN** на экране «Библиотека» видна карточка с обложкой (первая страница) и названием «english name»

#### Scenario: Ширина экрана
- **WHEN** окно ПК расширяется или приложение открыто на телефоне
- **THEN** число колонок сетки подстраивается под ширину, карточки не перекрываются

### Requirement: Счётчик и обновление
Над сеткой SHALL отображаться число галерей и кнопка «Обновить». Во время сканирования MUST показываться индикатор, а повторное нажатие «Обновить» MUST NOT запускать второе параллельное сканирование.

#### Scenario: Ручное обновление
- **WHEN** пользователь копирует новый архив в папку и нажимает «Обновить»
- **THEN** после сканирования новая карточка появляется первой, счётчик увеличивается

#### Scenario: Двойное нажатие
- **WHEN** пользователь нажимает «Обновить» во время идущего сканирования
- **THEN** новое сканирование не запускается

### Requirement: Автоматическое сканирование
Приложение MUST сканировать библиотеку при запуске и при каждом возврате приложения на передний план. Сканирование MUST выполняться в фоне, не блокируя интерфейс; результаты MUST применяться к виджетам через `fyne.Do`.

#### Scenario: Запуск
- **WHEN** приложение запускается, а в папке есть архивы
- **THEN** экран сразу доступен, а карточки появляются по завершении сканирования

#### Scenario: Возврат на передний план
- **WHEN** на Android пользователь сворачивает приложение, копирует архив по USB и возвращается
- **THEN** новый архив появляется без нажатия «Обновить»

### Requirement: Загрузка миниатюр
Обложки MUST загружаться в фоне только для видимых карточек. Первая страница декодируется (JPEG, PNG, GIF, WebP) и уменьшается до размера области обложки карточки в физических пикселях экрана с сохранением пропорций. Большая сторона миниатюры MUST NOT превышать 512 пикселей, изображение MUST NOT увеличиваться. Миниатюра кэшируется в памяти по ключу галереи с учётом времени изменения архива. Объём кэша MUST быть ограничен в байтах; при переполнении вытесняются давно не показанные миниатюры.

Если карточка переиспользована для другой галереи до начала декодирования прежней обложки, прежний запрос MUST отменяться без декодирования. Из ожидающих запросов MUST сначала выполняться более новые. Декодирование и уменьшение MUST выполняться вне UI-потока; UI-поток MUST NOT масштабировать миниатюру.

Пока миниатюра загружается, карточка MUST показывать заглушку. Если обложку не удалось декодировать, карточка MUST показывать значок ошибки, а не пустое место.

#### Scenario: Быстрая прокрутка
- **WHEN** пользователь прокручивает сетку и карточка повторно становится видимой
- **THEN** обложка берётся из кэша без повторного декодирования

#### Scenario: Битое изображение
- **WHEN** первая страница архива не является корректным изображением
- **THEN** карточка показывает значок ошибки и название, остальные карточки не затронуты

#### Scenario: Переиспользование карточки
- **WHEN** виджет карточки переиспользуется для другой галереи, пока грузится прежняя обложка
- **THEN** в карточке появляется обложка новой галереи, а не прежней

#### Scenario: Отмена ушедших с экрана
- **WHEN** пользователь быстро пролистывает сетку из 200 карточек до конца
- **THEN** обложки карточек, которые ушли с экрана до начала их декодирования, не декодируются, а обложки видимых карточек загружаются в первую очередь

#### Scenario: Размер миниатюры
- **WHEN** область обложки карточки занимает 450×640 физических пикселей, а первая страница имеет размер 1400×2000
- **THEN** миниатюра имеет размер не больше 358×512 и не больше области обложки

#### Scenario: Лимит кэша
- **WHEN** в кэш добавляются миниатюры сверх лимита объёма
- **THEN** объём кэша не превышает лимит, вытесняются давно не показанные миниатюры

### Requirement: Пустое состояние и ошибки
Если галерей нет, экран MUST показывать пустое состояние с папкой библиотеки (на ПК — полный путь, на Android — имя выбранной папки). Если папка на Android не выбрана или недоступна, вместо пустого состояния MUST показываться экран «Выберите папку с мангой» с кнопкой «Выбрать папку». Если сканирование нашло новые непросмотренные ошибки, MUST показываться toast с их количеством и указанием на вкладку «Ошибки»; список ошибок MUST записываться в лог. Уже известные ошибки MUST NOT вызывать toast повторно.

#### Scenario: Пустая папка
- **WHEN** в папке библиотеки нет архивов
- **THEN** показывается пустое состояние с папкой библиотеки

#### Scenario: Папка не выбрана
- **WHEN** на Android папка библиотеки не выбрана
- **THEN** показывается «Выберите папку с мангой» с кнопкой «Выбрать папку»

#### Scenario: Повреждённые архивы
- **WHEN** сканирование нашло 2 новых ошибочных файла
- **THEN** показывается toast «Новые ошибки: 2 — см. вкладку «Ошибки»», а корректные архивы отображаются

#### Scenario: Повторное сканирование
- **WHEN** папка с теми же 2 ошибочными файлами сканируется повторно
- **THEN** toast об ошибках не показывается

### Requirement: Нажатие на карточку
Нажатие на карточку SHALL открывать страницу произведения для этой галереи. После закрытия страницы произведения сетка MUST оставаться в прежнем положении прокрутки, а выделение карточки MUST быть снято.

#### Scenario: Нажатие
- **WHEN** пользователь нажимает на карточку `example.zip`
- **THEN** открывается страница произведения «english name»

#### Scenario: Возврат из страницы произведения
- **WHEN** пользователь прокрутил сетку, открыл карточку и закрыл страницу произведения
- **THEN** сетка показана в том же положении прокрутки, карточка не выделена
