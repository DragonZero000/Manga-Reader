# display-refresh Specification

## Purpose

Частота экрана окна приложения на Android: запрос режима 60 Гц, чтобы 60-герцовый такт отрисовки Fyne совпадал с экраном, и настройка «Ограничить 60 Гц» в разделе «Экран».

## Requirements
### Requirement: Частота экрана 60 Гц на Android
На Android, пока окно приложения на экране, приложение SHALL просить систему показывать его с частотой 60 Гц, если включена настройка «Ограничить 60 Гц». Для этого выбирается режим дисплея с тем же разрешением и частотой, ближайшей к 60 Гц; если такого режима нет, указывается предпочтительная частота 60 Гц. Если настройка выключена, приложение MUST NOT ограничивать частоту, и система выбирает её сама. Запрос MUST применяться при запуске и при каждом изменении настройки без перезапуска. Ошибка запроса MUST записываться в журнал и MUST NOT мешать работе приложения. Экран встроенного браузера этой настройкой MUST NOT затрагиваться.

#### Scenario: По умолчанию
- **WHEN** приложение впервые запускается на телефоне с экраном 120 Гц
- **THEN** окно приложения показывается с частотой 60 Гц

#### Scenario: Настройка выключена
- **WHEN** пользователь выключает «Ограничить 60 Гц»
- **THEN** сразу, без перезапуска, окно приложения показывается с частотой, которую выбирает система

#### Scenario: Нет режима 60 Гц
- **WHEN** у дисплея нет режима 60 Гц с текущим разрешением
- **THEN** приложение указывает предпочтительную частоту 60 Гц и продолжает работать

### Requirement: Раздел «Экран» в настройках
На Android экран «Настройки» SHALL содержать раздел «Экран» с флажком «Ограничить 60 Гц» и пояснением, что это делает прокрутку ровнее. По умолчанию флажок MUST быть включён. Значение MUST сохраняться в настройках и восстанавливаться при запуске. На платформах без этой функции раздел MUST NOT показываться.

#### Scenario: Сохранение
- **WHEN** пользователь выключает «Ограничить 60 Гц» и перезапускает приложение
- **THEN** флажок выключен, частота не ограничивается

#### Scenario: ПК
- **WHEN** пользователь открывает «Настройки» на Windows
- **THEN** раздела «Экран» нет
