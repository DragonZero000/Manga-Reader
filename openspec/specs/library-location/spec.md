# library-location Specification

## Purpose

Папка библиотеки: на ПК — папка manga рядом с исполняемым файлом (портативный режим, все файлы только в папке приложения), на Android — папка, выбранная пользователем через системный выбор; создание папки, выбор и смена папки, отображение в «Настройках».

## Requirements

### Requirement: Фиксированная папка библиотеки
На ПК папкой библиотеки SHALL быть подпапка `manga` в папке приложения. Папка приложения MUST определяться как каталог исполняемого файла; при запуске через `go run` (исполняемый файл во временном каталоге сборки) — как текущая рабочая папка. На Android папкой библиотеки SHALL быть папка, выбранная пользователем в системном диалоге выбора папки; путей, заданных приложением, на Android MUST NOT быть.

#### Scenario: Путь на Windows
- **WHEN** `mangareader.exe` лежит в `D:\Apps\MangaReader` и запускается
- **THEN** папкой библиотеки является `D:\Apps\MangaReader\manga`

#### Scenario: Запуск через go run
- **WHEN** приложение запущено командой `go run ./cmd/mangareader` из корня проекта
- **THEN** папкой библиотеки является `<корень проекта>\manga`

#### Scenario: Папка на Android
- **WHEN** пользователь выбрал в системном диалоге папку `Download/manga`
- **THEN** библиотека показывает архивы из этой папки и её подпапок

### Requirement: Создание папки при старте
На ПК приложение MUST создавать папку библиотеки, если она отсутствует, и MUST NOT изменять или удалять существующие в ней файлы. На Android приложение MUST NOT создавать папок: папку выбирает (и при необходимости создаёт в диалоге) пользователь.

#### Scenario: Первый запуск на ПК
- **WHEN** папки `manga` рядом с исполняемым файлом нет
- **THEN** приложение создаёт её, и она пуста

#### Scenario: Повторный запуск
- **WHEN** папка библиотеки уже существует и содержит файлы
- **THEN** приложение использует её без изменения содержимого

#### Scenario: Папку невозможно создать
- **WHEN** на ПК создание папки завершается ошибкой (например, нет прав на запись в папку приложения)
- **THEN** приложение продолжает работу и показывает toast-уведомление с текстом ошибки и путём

### Requirement: Отображение пути библиотеки
Экран «Настройки» SHALL показывать папку библиотеки: на ПК — полный путь, на Android — понятное имя выбранной папки (например, `Download/manga`) или «Папка не выбрана». На Android экран MUST содержать кнопку «Изменить папку», открывающую системный выбор папки.

#### Scenario: Просмотр пути на ПК
- **WHEN** пользователь открывает экран «Настройки» на ПК
- **THEN** отображается полный путь папки `manga` рядом с исполняемым файлом

#### Scenario: Смена папки на Android
- **WHEN** пользователь нажимает «Изменить папку» и выбирает другую папку
- **THEN** библиотека пересканируется и показывает архивы из новой папки, а в «Настройках» отображается её имя

### Requirement: Выбор папки на Android
При первом запуске на Android, когда папка ещё не выбрана, приложение SHALL сразу открывать системный выбор папки. Выбранная папка MUST запоминаться, а разрешение на чтение MUST сохраняться так, чтобы после перезапуска приложения и телефона выбор не требовался снова. Если выбор отменён, разрешение отозвано или папка удалена, приложение MUST показывать экран «Выберите папку с мангой» с кнопкой, открывающей системный выбор.

#### Scenario: Первый запуск
- **WHEN** приложение впервые запускается на Android
- **THEN** открывается системный выбор папки

#### Scenario: Перезапуск
- **WHEN** папка выбрана, приложение закрыто и запущено снова
- **THEN** библиотека показывает архивы из выбранной папки без повторного выбора

#### Scenario: Выбор отменён
- **WHEN** пользователь закрыл системный выбор, ничего не выбрав
- **THEN** показывается экран «Выберите папку с мангой» с кнопкой «Выбрать папку»

#### Scenario: Папка удалена
- **WHEN** выбранная папка удалена или переименована
- **THEN** при следующем сканировании показывается экран «Выберите папку с мангой»

### Requirement: Файлы только в папке приложения на ПК
На ПК приложение MUST NOT создавать и изменять файлы вне папки приложения. Настройки приложения MUST храниться в `settings.json` в папке приложения.

#### Scenario: Ничего в профиле пользователя
- **WHEN** приложение запущено, режим читалки переключён и приложение закрыто
- **THEN** в `%APPDATA%\fyne` и в профиле пользователя не появилось и не изменилось ни одного файла приложения, а режим сохранён в `settings.json` рядом с исполняемым файлом
