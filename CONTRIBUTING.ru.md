# Участие в разработке

Спасибо, что хотите помочь! Ниже — как устроена работа над проектом.

## Сообщить о проблеме

Откройте [issue](https://github.com/DragonZero000/Manga-Reader/issues): версия приложения (**Настройки** → **О приложении**), платформа (Windows / Android и версия), что делали, что ожидали, что получили. Если проблема с конкретным архивом — опишите его содержимое (список файлов, есть ли `meta.json`), сам архив прикладывать не нужно.

## Предложить изменение

1. Форкните репозиторий и создайте ветку от `main`.
2. Соберите и запустите проект — см. [docs/ru/building.md](docs/ru/building.md).
3. Для заметного изменения (новая функция, изменение поведения) сначала опишите его в issue или через OpenSpec (ниже). Мелкие исправления можно присылать сразу.
4. Перед pull request выполните `make test` — он же запускается в CI на каждый push и pull request.
5. Откройте pull request с описанием: что и зачем изменено, как проверено, на каких платформах.

## Процесс OpenSpec

Требования и история решений хранятся в [`openspec/`](openspec/) ([OpenSpec](https://github.com/Fission-AI/OpenSpec)):

- `openspec/specs/` — действующие требования со сценариями; меняйте их вместе с поведением;
- `openspec/changes/<имя>/` — изменение в работе: `proposal.md` (зачем), `design.md` (как и почему так), `specs/` (дельта требований), `tasks.md` (задачи);
- `openspec/changes/archive/` — завершённые изменения;
- `openspec/config.yaml` — контекст проекта и правила для новых изменений.

Команды и скиллы для AI-ассистентов (Claude Code, Cline и др.) в репозиторий не входят — у каждого свои: `npm install -g @fission-ai/openspec` и `openspec init` создадут их локально (папки `.claude/`, `.cline/`, `.clinerules/` в `.gitignore`).

## Правила

- **Документация на двух языках.** Меняете поведение для пользователя или сборку — обновите `docs/en/` и `docs/ru/` (и `README.md` / `README.ru.md`) в том же pull request. Не знаете один из языков — напишите на своём и отметьте это в pull request, перевод доделаем. `make test` проверяет, что у каждого документа есть пара, переключатель языка и рабочие ссылки.
- **Строки интерфейса — на русском**, пока в приложении нет перевода интерфейса. Комментарии в коде — на русском.
- **Виджеты Fyne — только в `internal/ui/...`.** Новый пакет в `internal/` добавьте в `internal/archtest/imports_test.go` и в [docs/ru/architecture.md](docs/ru/architecture.md) / [docs/en/architecture.md](docs/en/architecture.md).
- **UI меняется только из основного потока** — через `fyne.Do` из горутин.
- **Платформенный код** — через build-теги и суффиксы файлов, с заглушкой для остальных платформ.
- **Сторонние компоненты.** Меняете версию Firefox ESR (`tools/fetch-firefox`), GeckoView (`android/app/build.gradle.kts`) или модули в `go.mod` — обновите [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- **Версию и релизы** меняет мейнтейнер: не правьте `Version` в `FyneApp.toml` в pull request.
